# 莫斯科图书馆信息指南

**数据说明**: 本指南基于公开可查信息整理

---

## 行业概述

莫斯科图书馆资源丰富，包括世界级的国家图书馆、历史悠久的大学图书馆和现代化的公共图书馆。俄罗斯国家图书馆是欧洲最大的图书馆之一，藏书超过3500万册。

## 推荐图书馆

### 俄罗斯国家图书馆 (Российская государственная библиотека)
- **地址**: ул. Воздвиженка, д. 3/5, Москва
- **特色**: 俄罗斯最大图书馆，欧洲最大图书馆之一。藏书超过3500万册，涵盖所有学科领域。拥有多个阅览室、数字资源和特藏部。建筑为新古典主义风格，穹顶大厅是其标志。
- **开放时间**: 周一至周六 9:00–21:00，周日休息
- **借阅**: 需办理读者卡（护照原件），当日可取
- **交通**: 地铁 Библиотека им. Ленина 站 / Боровицкая 站

### 列宁图书馆 (Библиотека им. В.И. Ленина)
- **地址**: ул. Воздвиженка, д. 3/5, Москва
- **说明**: 即俄罗斯国家图书馆的旧称，习惯上仍常用此名称

### 俄罗斯国家图书馆儿童馆 (Российская государственная библиотека для детей)
- **地址**: ул. Миусская 1-я, д. 16, Москва
- **特色**: 俄罗斯最大的儿童图书馆，藏书超过100万册。设有绘本阅览室、多媒体区和活动空间。经常举办儿童读书会和工作坊。
- **开放时间**: 周二至周六 10:00–19:00，周日、周一休息
- **交通**: 地铁 Новослободская 站 / Достоевская 站

### 莫斯科大学图书馆 (Научная библиотека МГУ)
- **地址**: Ломоносовский пр., д. 27, Москва
- **特色**: 莫斯科国立大学的主图书馆，藏书丰富，尤其在自然科学和人文科学方面。面向全校师生开放，部分阅览室对外部访客开放。
- **开放时间**: 周一至周五 9:00–20:00，周六 9:00–17:00
- **交通**: 地铁 Университет 站

### 普希金造型艺术图书馆 (Библиотека по искусству)
- **地址**: ул. Волхонка, д. 12, Москва
- **特色**: 与普希金造型艺术博物馆相邻，收藏艺术、建筑、设计类书籍和期刊。设有艺术期刊阅览室和展览空间。
- **开放时间**: 周三至周一 11:00–18:00
- **交通**: 地铁 Кропоткинская 站 / Боровицкая 站

### 公共图书馆网络

**莫斯科中央图书馆 (Центральная библиотека им. В.В. Маяковского)**
- **地址**: ул. Большая Якиманка, д. 19, Москва
- **特色**: 莫斯科最大的公共图书馆之一，藏书涵盖文学、历史、科学等领域。设有多个阅览室、自习室和数字资源区。
- **开放时间**: 周一至周六 10:00–21:00，周日 11:00–19:00
- **交通**: 地铁 Полянка 站 / Октябрьская 站

** библиотека им. Н.В. Гоголя (Гоголевская библиотека)**
- **地址**: ул. Каретный Ряд, д. 5/10, Москва
- **特色**: 以俄罗斯文学巨匠果戈理命名的公共图书馆。收藏俄语文学经典、外国文学译著。有丰富的藏书和安静的学习环境。
- **开放时间**: 周二至周六 10:00–20:00
- **交通**: 地铁 Чеховская 站 / Тверская 站

### 专业图书馆

**国家科技图书馆 (Всероссийская академическая библиотека)**
- **地址**: Нахимовский пр., д. 51, Москва
- **特色**: 收藏科学技术类文献，包括专利、标准、科研报告等。
- **开放时间**: 周一至周五 9:00–18:00

## 服务特色

### 读者卡办理
- 俄罗斯公民：护照原件
- 外国公民：护照原件和居住地址证明
- 当日可取，有效期通常为1年

### 数字资源
- 大多数图书馆提供电子目录和数据库访问
- 部分图书馆提供WiFi和电脑使用

### 特殊服务
- 视障读者专区（有声书和盲文资料）
- 儿童专区（绘本、教育资源）
- 多媒体区（音视频资源）

## 消费提示

- 基本借阅服务通常免费
- 逾期罚款约1-5 ₽/天
- 数字资源使用免费，但部分数据库需订阅
- 复印服务约3-10 ₽/页
- 停车位有限，建议使用公共交通
