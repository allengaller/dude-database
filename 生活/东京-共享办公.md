# 东京共享办公信息指南

**数据说明**: 本指南基于公开可查信息整理

## 行业概述

东京是亚洲共享办公最发达的城市，联合办公空间（Co-working）集中于六本木、涉谷和丸之内。东京共享办公以服务科技、金融和创业公司为主，价格亚洲最高，与纽约、伦敦相当。WeWork、Spaces和JustCo是主要品牌。

## 推荐共享办公空间

### 国际连锁品牌

**WeWork（东京）**
- **地址**: 东京都港区六本木1-4-5（六本木新城，多家门点）
- **特色**: 全球最大共享办公品牌，在东京拥有超过20个门店。装修现代，社群活跃。全球会员可预约使用。
- **价格**: 浮动工位¥60,000–100,000/月，固定工位¥100,000–180,000/月，私人办公室¥180,000–400,000/月
- **设施**: 高速WiFi、会议室、咖啡茶饮、打印、24小时出入
- **交通**: 地铁日比谷线六本木站

**Spaces（六本木）**
- **地址**: 东京都港区六本木6-2-31（六本木 Hills座）
- **特色**: IWG集团旗下中高端共享办公品牌，适合企业客群和跨国公司。位置优越，服务专业。
- **价格**: 固定工位¥80,000–150,000/月，私人办公室¥150,000–300,000/月
- **设施**: WiFi、会议室、前台服务、咖啡区
- **交通**: 地铁日比谷线六本木站

### 本土品牌

**JustCo（东京）**
- **地址**: 东京都千代田区大手町1-9-2（丸之内金融中心，多家门点）
- **特色**: 亚太区共享办公品牌，服务跨国企业和初创公司。日本市场扩张迅速。
- **价格**: 固定工位¥70,000–130,000/月，私人办公室¥130,000–280,000/月
- **设施**: WiFi、会议室、前台、咖啡区
- **交通**: 地铁丸之内线大手町站

**Fabbit（法比特）**
- **地址**: 东京都港区芝公园3-4-30（多家分店）
- **特色**: 日本本土共享办公品牌，在核心商圈有多个据点。适合中小企业和创业者。
- **价格**: 开放工位¥40,000–70,000/月，固定工位¥60,000–100,000/月
- **设施**: WiFi、会议室、仓储
- **交通**: 地铁都営三田线芝公园站

### 创意园区共享办公

**Tokyo Node Lab（东京节点实验室）**
- **地址**: 东京都江区青海2-7-1（东京港区青海）
- **特色**: 位于台场的创新园区，配备最新办公设施。适合科技和创意从业者。
- **价格**: 固定工位¥50,000–90,000/月
- **设施**: WiFi、VR工作室、会议室
- **交通**: 海鸥线青海站

**Cosmograph（宇宙图）**
- **地址**: 东京都渋谷区神宫前3-7-10（表参道区）
- **特色**: 专为创意工作者设计的共享办公空间。艺术氛围浓厚，适合设计师。
- **价格**: 固定工位¥70,000–120,000/月
- **设施**: WiFi、展厅、摄影棚
- **交通**: 地铁千代田线表参道站

### 数字游民友好

**WeWork Atto（威尔工作阿托）**
- **地址**: 东京都港区虎之门1-17-1（虎之门Hill座）
- **特色**: 专为个人创业者和数字游民设计的小型共享办公。提供按日计费选项。
- **价格**: 按日¥3,000–5,000，按月¥80,000–150,000
- **设施**: WiFi、咖啡、储物柜、视频会议室
- **交通**: 地铁千代田线虎之门站

**Business Airplant（商业空气站）**
- **地址**: 东京都千代田区丸之内1-1-1丸之内广场
- **特色**: 机场型共享办公，提供即插即用工位。适合商务旅客。
- **价格**: 按小时¥1,000–2,000
- **设施**: WiFi、会议室、快递服务
- **交通**: JR东京站丸之内口

## 消费提示

- 东京共享办公价格亚洲最高，与纽约伦敦相当
- 六本木和丸之内是共享办公最集中区域
- WeWork和JustCo支持全球会员预约
- 长期租赁（6个月以上）通常有折扣
- 多数空间支持信用卡和PayPay付款
