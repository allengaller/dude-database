# 首尔网红打卡点信息指南

**数据说明**: 本指南基于公开可查信息整理

---

## 行业概述

首尔是全球最具吸引力的旅游城市之一，打卡点从传统宫阙到新晋潮点应有尽有。景福宫和北村韩屋村是传统文化体验，明洞和弘大是时尚购物热点。K-beauty和韩流文化是重要体验元素。

## 推荐打卡点

### 传统文化

**景福宫（Gyeongbokgung）**
- **地址**: 首尔市钟路区社稷路161
- **特色**: 朝鲜王朝首要王宫，规模最大。守卫换岗仪式和兴礼门是经典场景。
- **拍照亮点**: 兴礼门、王宫内部、赤色宫墙
- **门票**: ₩3,000（韩服体验免费）
- **交通**: 地铁3号线景福宫站（5号出口）
- **最佳时间**: 清晨（8:30开门）或傍晚

**北村韩屋村（Bukchon Hanok Village）**
- **地址**: 首尔市钟路区桂洞115-1
- **特色**: 保存完好的传统韩屋村落，600年以上历史。俯瞰首尔市中心。
- **拍照亮点**: 韩屋小巷、传统瓦顶、首尔塔背景
- **门票**: 免费
- **交通**: 地铁3号线安国站（步行10分钟）
- **最佳时间**: 平日早场或傍晚

### 时尚街区

**明洞（Myeong-dong）**
- **地址**: 首尔市中区明洞2街
- **特色**: 首尔购物和时尚中心，K-beauty和韩流商品丰富。街头美食多样。
- **拍照亮点**: 街景、霓虹灯、各类店铺
- **门票**: 免费
- **交通**: 地铁4号线明洞站
- **最佳时间**: 下午至晚间

**弘大入口站周边（Hongdae）**
- **地址**: 首尔市麻浦区延南洞 / 西桥洞
- **特色**: 年轻人文化和艺术区，街头表演、独立设计和创意店铺。涂鸦墙和街舞表演。
- **拍照亮点**: 街头表演、涂鸦墙、创意店铺
- **门票**: 免费
- **交通**: 地铁2号线弘大入口站
- **最佳时间**: 周末下午

### 现代地标

**首尔塔（N Seoul Tower）**
- **地址**: 首尔市龙山区南山公园路1
- **特色**: 首尔标志性建筑，位于南山上。锁头墙和观景台是打卡热点。
- **拍照亮点**: 锁头墙、观景台俯瞰夜景
- **门票**: 缆车往返₩14,000
- **交通**: 地铁4号线明洞站（步行15分钟）
- **最佳时间**: 日落前到达看夜景

**Starfield河南（Starfield COEX Mall）**
- **地址**: 首尔市江南区三成洞159
- **特色**: 大型购物中心，室内瀑布和星空主题是亮点。SMTOWN是K-POP粉丝朝圣地。
- **拍照亮点**: 室内瀑布、K-POP体验
- **门票**: 免费
- **交通**: 地铁2号线三成站

### 艺术空间

**Leeum 三星美术馆**
- **地址**: 首尔市麻浦区合井洞320-4
- **特色**: 三星集团私立美术馆，建筑由Jean Nouvel设计。经常举办国际艺术家展览。
- **拍照亮点**: 建筑外观、展览空间
- **门票**: ₩10,000
- **交通**: 地铁6号线上水站（步行10分钟）

**Common Ground（共同空间）**
- **地址**: 首尔市广津区建国路838
- **特色**: 韩国最大集装箱购物中心，由200个蓝色集装箱构成。时尚设计，拍照效果好。
- **拍照亮点**: 集装箱外立面、入口广场
- **门票**: 免费
- **交通**: 地铁7号线绿莎坪站（步行10分钟）

## 拍照技巧

- **最佳时间**: 平日清晨或周末晚间
- **穿搭建议**: 韩屋村适合传统韩服，明洞适合街头时尚
- **必备App**: Instagram、VSCO
- **注意**: 部分场所禁止商业拍摄
