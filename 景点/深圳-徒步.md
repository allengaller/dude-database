# 深圳徒步信息指南

**数据说明**: 本指南基于公开可查信息整理

---

## 行业概述

深圳是徒步爱好者的天堂，从梧桐山、七娘山到东西涌穿越，路线多样。深圳有22座山峰海拔超过500米，郊野公园和绿道网络完善。东西涌穿越是中国十大经典徒步路线之一。

## 推荐徒步路线

### 经典徒步路线

**梧桐山登顶**
- **地址**: 深圳市盐田区
- **路线**: 梧桐山南地铁站→泰山涧→大梧桐顶（约8公里）
- **难度**: 中高（海拔943.7米，爬升约800米）
- **特色**: 深圳最高峰，登顶俯瞰深港两地
- **门票**: 免费
- **建议时间**: 4–6小时
- **注意**: 路线较长，建议早出发

**七娘山登顶**
- **地址**: 深圳市大鹏新区
- **路线**: 七娘山国家地质公园入口→主峰（约7公里）
- **难度**: 中高（海拔867米）
- **特色**: 深圳第二高峰，三面环海，视野开阔
- **门票**: 免费（需预约）
- **建议时间**: 5–7小时
- **注意**: 部分路段陡峭

**东西涌穿越**
- **路线**: 东涌→西涌海岸线（约8公里）
- **难度**: 中等（需穿越礁石）
- **特色**: 中国十大经典徒步路线之一，壮丽的海蚀地貌
- **门票**: 免费
- **建议时间**: 4–6小时
- **注意**: 需携带手套，礁石湿滑，防晒必备

### 海岸徒步

**大鹏半岛国家地质公园海岸线**
- **路线**: 鹿嘴山庄→杨梅坑（约5公里）
- **难度**: 简单至中等
- **特色**: 《美人鱼》拍摄地，海蚀地貌
- **建议时间**: 3–4小时

**大梅沙至小梅沙栈道**
- **路线**: 大梅沙海滨公园至小梅沙（约3公里）
- **难度**: 简单
- **特色**: 沿海栈道，景色优美
- **建议时间**: 1–2小时

### 山林休闲徒步

**塘朗山郊野公园**
- **路线**: 桃源村地铁站→塘朗山主峰（约6公里）
- **难度**: 中等
- **特色**: 野生猕猴出没，俯瞰深圳湾
- **门票**: 免费
- **建议时间**: 3–4小时

**阳台山森林公园**
- **路线**: 阳台山广场→主峰（约5公里）
- **难度**: 中等
- **特色**: 宝安区最高峰，溪流瀑布
- **门票**: 免费
- **建议时间**: 3–5小时

**银湖山郊野公园**
- **路线**: 银湖山入口→主峰（约4公里）
- **难度**: 中等
- **特色**: 离市区近，适合平日短途
- **门票**: 免费

### 绿道徒步

**梧桐山绿道**
- **路线**: 梧桐山北门→梧桐山村（约10公里）
- **难度**: 简单至中等
- **特色**: 沿途竹林、溪流
- **建议时间**: 3–4小时

**大运公园绿道**
- **路线**: 大运公园→神仙湖（约8公里）
- **难度**: 简单
- **特色**: 绿化好，人少
- **建议时间**: 2–3小时

## 徒步装备建议

| 装备 | 说明 |
|------|------|
| 登山鞋/防滑鞋 | 礁石和山路湿滑 |
| 登山杖 | 爬山必备 |
| 足够饮用水 | 2–3升 |
| 防晒用品 | 防晒霜、帽子 |
| 手套 | 东西涌穿越必备 |
| 雨衣 | 雨季必备 |
| 头灯 | 登山必备 |

## 安全提示

- 梧桐山、七娘山等高山路线建议结伴而行
- 东西涌穿越注意潮汐时间，涨潮时可能封闭
- 雨季（5–9月）注意山洪和滑坡
- 夏季高温避免中午登山
- 不熟悉的路线建议跟团或请向导
- 登山前告知家人行程
