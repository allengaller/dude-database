# 杭州公园信息指南

**数据说明**: 本指南基于公开可查信息整理

---

## 行业概述

杭州是著名"公园城市"，截至2025年各类公园超过1,000座。西湖是杭州最著名的"公园"，2011年列入世界文化遗产。千岛湖、西溪湿地是杭州另外两张生态名片。市区内还有众多社区公园和城市绿道。

## 推荐公园

### 世界文化遗产

**西湖**
- **地址**: 杭州市西湖区
- **特色**: 世界文化遗产，中国最美湖泊之一。苏堤春晓、断桥残雪、三潭印月等"西湖十景"闻名世界
- **门票**: 免费（部分景点如雷峰塔需购票）
- **交通**: 地铁1号线龙翔桥站、西湖文化广场站
- **活动**: 泛舟、漫步、赏花

### 城市公园

**西溪湿地国家公园**
- **地址**: 杭州市西湖区天目山路
- **面积**: 约11.5平方公里
- **特色**: 中国首个湿地公园，《非诚勿扰》拍摄地。生态保护完好，有"城市绿肾"之称
- **门票**: ¥80（大门票），电瓶船¥60
- **交通**: 地铁2号线丰潭路站
- **建议游览**: 半天至一天

**千岛湖（淳安）**
- **地址**: 杭州市淳安县（距杭州约2.5小时车程）
- **特色**: 农夫山泉取水地，1,078个岛屿星罗棋布
- **门票**: 中心湖区¥130+船票65，东南湖区¥110+船票65
- **交通**: 建议自驾，或杭州东站有直达巴士
- **建议游览**: 2–3天

**太子湾公园**
- **地址**: 杭州市西湖区南山路
- **面积**: 约20公顷
- **特色**: 春季樱花、郁金香盛开，是杭州最著名的赏花圣地
- **开放时间**: 全天
- **门票**: 免费
- **交通**: 地铁1号线龙翔桥站步行
- **最佳季节**: 3月中下旬至4月初

**杭州植物园**
- **地址**: 杭州市西湖区玉泉
- **面积**: 约237公顷
- **特色**: "灵峰探梅"是杭州冬季最著名的赏梅胜地
- **门票**: ¥10
- **交通**: 地铁3号线至黄龙体育中心站
- **最佳季节**: 12月至次年2月（赏梅）

**宋城公园**
- **地址**: 杭州市西湖区之江路
- **特色**: 宋城景区入口处，可免费参观
- **门票**: 免费（看演出需购票）
- **交通**: 地铁6号线至之江文化中心站

### 社区公园

**运河公园（拱宸桥区域）**
- **地址**: 杭州市拱墅区运河两岸
- **特色**: 沿京杭大运河，有拱宸桥、桥西直街、小河直街等历史街区
- **门票**: 免费
- **交通**: 地铁5号线大运河站
- **活动**: 夜游运河、逛历史街区

**白塔公园**
- **地址**: 杭州市上城区老复兴街
- **特色**: 始建于唐代的的白塔，公园内有老火车站
- **门票**: 免费
- **交通**: 地铁4号线水澄桥站

**滨江公园（钱塘江畔）**
- **地址**: 杭州市滨江区钱塘江南岸
- **特色**: 沿江16公里绿道，可观赏钱塘江大桥
- **门票**: 免费
- **交通**: 地铁1号线至滨和路站
- **活动**: 骑行、跑步、夜景

### 特色公园

**八卦田遗址公园**
- **地址**: 杭州市上城区玉皇山脚下
- **特色**: 南宋皇家籍田，八卦形水田
- **门票**: 免费
- **交通**: 地铁4号线水澄桥站

**铜鉴湖公园**
- **地址**: 杭州市西湖区双浦镇
- **特色**: 新建花海公园，粉黛乱子草花海
- **门票**: 免费
- **交通**: 建议自驾

| 设施类型 | 分布 | 说明 |

| 健身步道 | 西湖、湘湖、滨江 | 免费使用 |
| 儿童游乐场 | 各区公园 | 安全认证 |
| 茶室 | 西湖周边 | 品茶赏景 |
| 游船 | 西湖、西溪湿地 | 按小时或次计费 |

## 消费提示

- 西湖所有城市公园免费开放
- 千岛湖和西溪湿地需购门票
- 春季太子湾公园人流量极大，建议工作日前往
- 夏季西湖边注意防晒
- 节假日西湖周边交通管制，建议公共交通
