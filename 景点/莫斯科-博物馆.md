# 莫斯科博物馆指南

**数据说明**: 本指南基于公开可查信息整理

---

## 行业概述

莫斯科是世界博物馆资源最丰富的城市之一，拥有超过400座各类博物馆。从红场旁的国家历史博物馆到特列季亚科夫画廊，莫斯科的博物馆收藏涵盖了俄罗斯千年历史、世界级艺术珍品和苏联时代的科技遗产，体系完整、藏品丰厚。

莫斯科的博物馆多坐落于历史建筑之中，参观体验本身就是一次建筑与历史的沉浸之旅。近年来各馆纷纷进行现代化改造，增设多媒体互动展项，在保留深厚学术底蕴的同时提升了观展体验。

莫斯科博物馆门票价格相对欧洲城市十分亲民，多数国立博物馆门票在300-700卢布之间。地铁网络覆盖几乎所有主要场馆，出行极为便利。建议游客根据兴趣选择2-3座重点场馆深度游览，而非走马观花。

## 推荐博物馆

### 综合/国家级

**Государственный исторический музей / 国家历史博物馆（红场）**
- **地址**: Красная площадь, 1, Москва, 109012
- **特色**: 红场北端的深红色建筑是莫斯科最具辨识度的地标之一。馆藏超过500万件，从石器时代到20世纪初的俄罗斯历史文物一应俱全。金色穹顶大厅和按年代编排的展厅令人叹为观止。每个展厅天花板装饰各不相同，建筑细节本身即为艺术品。
- **门票**: 成人500卢布，学生200卢布
- **交通**: 地铁Охотный Ряд站或Площадь Революции站

**Государственный музей изобразительных искусств им. А.С. Пушкина / 普希金造型艺术博物馆（中心）**
- **地址**: ул. Волхонка, 12, Москва, 119019
- **特色**: 俄罗斯最大的外国艺术收藏馆，藏有古埃及、古希腊罗马文物及欧洲绘画大师作品。印象派和后印象派收藏（莫奈、雷诺阿、塞尚、梵高）极为珍贵。19-20世纪欧美艺术分馆位于隔壁大楼，藏有马蒂斯、毕加索立体主义时期作品，同样不可错过。
- **门票**: 成人500卢布
- **交通**: 地铁Кропоткинская站步行约3分钟

### 艺术/画廊

**Государственная Третьяковская галерея / 特列季亚科夫画廊（扎莫斯科沃列奇耶）**
- **地址**: Лаврушинский пер., 10, Москва, 119017
- **特色**: 世界最大的俄罗斯美术收藏馆，馆藏超过18万件。列宾《伏尔加河上的纤夫》、苏里科夫《近卫军临刑的早晨》、安德烈·鲁布廖夫《三位一体》等俄罗斯绘画巅峰之作均收藏于此。新馆（Крымский Вал）展出20世纪先锋派和苏联时期作品，两馆互补。
- **门票**: 成人600卢布
- **交通**: 地铁Третьяковская站步行约5分钟

**Музей современного искусства «Гараж» / 车库当代艺术博物馆（高尔基公园）**
- **地址**: ул. Крымский Вал, 9, стр. 32, Москва, 119049
- **特色**: 由Rem Koolhaas/OMA设计改造，是俄罗斯最重要的当代艺术机构。聚焦国际当代艺术前沿，定期举办大型个展和主题群展，设有俄罗斯当代艺术档案库。馆内书店和咖啡厅是莫斯科文艺青年的热门聚集地。
- **门票**: 成人700卢布
- **交通**: 地铁Парк Культуры站步行约10分钟

### 专题/军事/航天

**Музей космонавтики / 航天博物馆（VDNKh）**
- **地址**: просп. Мира, 111, Москва, 129366
- **特色**: 位于"征服太空"纪念碑基座内，展示苏联及俄罗斯航天史。馆藏加加林太空服、东方号飞船返回舱、月球车实物等珍贵航天文物，是太空迷的朝圣之地。馆内还设有太空食品品尝区和航天模拟器体验项目。
- **门票**: 成人450卢布
- **交通**: 地铁ВДНХ站步行约5分钟

**Оружейная палата / 军械库（克里姆林宫）**
- **地址**: Кремль, Москва, 103132
- **特色**: 克里姆林宫内最古老的博物馆，收藏沙皇时代皇家珍宝。法贝热彩蛋、沙皇王冠、皇家马车、中世纪武器铠甲为镇馆之宝。展厅按主题分为金银器、武器、服饰和马车等区域，每件展品都彰显俄罗斯帝国的辉煌。参观需购买克里姆林宫门票并单独预约。
- **门票**: 成人1000卢布（含克里姆林宫门票需另购）
- **交通**: 地铁Александровский Сад站或Боровицкая站

## 参观建议

- 克里姆林宫军械库每日限流，务必提前在官网预约指定时段
- 特列季亚科夫画廊新馆（Крымский Вал）展出20世纪苏联艺术，与老馆互补，建议两馆都看
- 多数博物馆周一闭馆，普希金博物馆和特列季亚科夫画廊周三延长至21:00
- 建议购买博物馆通票或关注每月免费开放日（通常为每月第三个周日）
- 冬季（11-3月）是博物馆游览旺季，室内温暖舒适，建议避开新年假期人流
- 各馆均提供俄语和英语导览，部分场馆有中文语音导览器可租借
- 红场周边（国家历史博物馆、克里姆林宫）安检较严格，建议轻装前往
- 高尔基公园区域可安排半日游：车库当代艺术博物馆+公园漫步+河畔咖啡
- 莫斯科地铁本身即为建筑艺术，前往各馆途中可欣赏车站装饰
- 夏季（6-8月）白昼时间长，适合博物馆与城市观光交替进行
- 普希金博物馆与特列季亚科夫画廊距离较近，可安排同一天参观
- 建议穿着舒适鞋子，各馆展厅面积大，步行量较高
