# 上海图书馆指南

## 1. 公共图书馆

### 上海图书馆
- **地址**: 上海市徐汇区淮海中路1555号
- **特色**: 上海市中心图书馆，藏书丰富，设施齐全，文化活动丰富
- **适合人群**: 全年龄段，学生，学者，书虫

### 上海少年儿童图书馆
- **地址**: 上海市静安区南京西路962号
- **特色**: 专门为儿童和青少年服务的图书馆，儿童读物丰富，活动多样
- **适合人群**: 儿童，青少年，家长

### 上海各区图书馆
- **地址**: 上海市各区
- **特色**: 分布在各区，方便就近借阅，藏书丰富，设施齐全
- **适合人群**: 全年龄段，周边居民，学生

## 3. 特色图书馆

- **地址**: 上海市各区

- **适合人群**: 书虫，文艺青年，摄影爱好者

### 上海茑屋书店
- **地址**: 上海市浦东新区前滩太古里

- **适合人群**: 书虫，文艺青年，摄影爱好者

## 5. 图书馆使用指南

1. **办卡须知**:
   - 上海图书馆：携带身份证，免费办理
   - 各区图书馆：携带身份证，免费办理
   - 高校图书馆：仅限本校师生使用

2. **开放时间**:
   - 上海图书馆：周一至周日 9:00-21:00（具体时间以官网为准）
   - 各区图书馆：周一至周日 9:00-20:00（具体时间以官网为准）
   - 特色图书馆：根据具体场馆而定

3. **借阅规则**:
   - 上海图书馆：可借阅图书10册，期限28天，可续借一次
   - 各区图书馆：可借阅图书8册，期限28天，可续借一次
   - 特色图书馆：部分仅提供阅读，不提供外借

4. **注意事项**:
   - 保持安静，遵守图书馆规章制度
   - 爱护图书，避免损坏
   - 按时归还图书，避免逾期罚款
