# 上海桌游指南

**数据说明**: 本指南基于公开可查信息整理

---

## 行业概述

上海是国内桌游文化的发源地和重镇。从早期的桌游吧到如今的血染钟楼专场、桌游展会（Dice Con），上海拥有最成熟的桌游生态。人民广场、徐家汇、五角场、张江是桌游吧最密集的区域。上海桌游圈以深度策略玩家和社交派对玩家并重，既有重度德式桌游俱乐部，也有轻松的狼人杀吧。

## 推荐场所

### 专业桌游吧

**棋人一所桌游吧（人民广场店）**
- **地址**: 上海市黄浦区福州路
- **特色**: 上海老牌桌游吧，藏书量全市领先。涵盖德式策略、美式主题、派对游戏等300+款。有专门的血染钟楼房间和剧本杀房。店长是上海桌游圈意见领袖。
- **参考价格**: ¥48–68/人（不限时）
- **交通**: 地铁1/2/8号线人民广场站

**乐聚桌游俱乐部（徐家汇店）**
- **地址**: 上海市徐汇区肇嘉浜路
- **特色**: 徐家汇区域最大桌游吧，主打中重度德式策略桌游。定期举办桌游教学活动和比赛。环境安静，适合深度玩家。
- **参考价格**: ¥50–80/人
- **交通**: 地铁1/9/11号线徐家汇站

**玩聚桌游吧（五角场店）**
- **地址**: 上海市杨浦区淞沪路
- **特色**: 五角场大学城区域人气桌游吧，靠近复旦和同济大学。以派对游戏和社交推理为主，大学生群体活跃。
- **参考价格**: ¥35–55/人
- **交通**: 地铁10号线五角场站

### 血染钟楼/社交推理

**Bloody Tower血染钟楼馆（静安店）**
- **地址**: 上海市静安区南京西路
- **特色**: 上海第一家专业血染钟楼场馆，拥有认证说书人（Storyteller）。每周举办公开场和私人定制场。剧本涵盖官方板子和自制板子。
- **参考价格**: ¥68–98/人/场
- **交通**: 地铁2/7号线静安寺站

### 桌游+酒吧/咖啡

**Board Game Cafe桌游咖啡（张江店）**
- **地址**: 上海市浦东新区张江高科
- **特色**: 张江科技园区域桌游咖啡厅，白领午休和下班后社交热门场所。提供精品咖啡和轻食。
- **参考价格**: ¥45–65/人（含一杯饮品）
- **交通**: 地铁2号线张江高科站

## 消费提示

- 上海桌游吧密度全国最高，人民广场3公里内可找到10家以上
- 血染钟楼需提前在微信群/小程序预约组队
- Dice Con桌游展每年在上海举办，是全国最大桌游展
- 部分高端桌游吧提供包房服务，适合团建
