# 圣彼得堡图书馆信息指南

**数据说明**: 本指南基于公开可查信息整理

---

## 行业概述

圣彼得堡图书馆资源丰富，拥有世界级的历史文献收藏和现代化的公共图书馆网络。俄罗斯国家图书馆（РФ）主馆位于圣彼得堡，是俄罗斯最大的图书馆之一，藏书超过3500万册。

## 推荐图书馆

### 俄罗斯国家图书馆 (Российская национальная библиотека)
- **地址**: Октябрьская наб., д. 1/3, Санкт-Петербург
- **特色**: 俄罗斯最大的图书馆之一，藏书超过3500万册。收藏涵盖所有学科领域，包括珍贵的手稿、古版书和地图。主建筑为新古典主义风格，穹顶阅览室是标志性空间。提供视障读者专用服务。
- **开放时间**: 周一至周六 9:00–21:00，周日休息
- **借阅**: 需办理读者卡（护照原件），当日可取
- **交通**: 地铁 Гостиный двор 站 / Невский проспект 站

### 俄罗斯国家图书馆儿童馆 (Российская национальная библиотека для детей)**
- **地址**: ул. Марата, д. 72, Санкт-Петербург
- **特色**: 圣彼得堡最大的儿童图书馆，藏书超过30万册。设有绘本专区、多媒体区和儿童活动室。经常举办儿童读书会、绘本分享和教育工作坊。
- **开放时间**: 周二至周六 10:00–19:00
- **交通**: 地铁 Достоевская 站 / Маяковская 站

### 圣彼得堡国立大学图书馆 (Научная библиотека СПбГУ)
- **地址**: Университетская наб., д. 7/9, Санкт-Петербург
- **特色**: 圣彼得堡国立大学的主图书馆，创建于1724年。藏书丰富，尤其在历史、文学、法律和自然科学方面。面向全校师生开放，部分阅览室对访客开放。
- **开放时间**: 周一至周五 9:00–20:00，周六 9:00–17:00
- **交通**: 地铁 Адмиралтейская 站 / Васька 站

### 俄罗斯博物馆图书馆 (Научная библиотека Русского музея)
- **地址**: Инженерная ул., д. 4, Санкт-Петербург
- **特色**: 附属于俄罗斯博物馆的艺术专业图书馆。收藏艺术史、博物馆学和文物保护类书籍。设有艺术期刊阅览室，展出博物馆研究成果。
- **开放时间**: 周三至周一 10:00–18:00
- **交通**: 地铁 Гостиный двор 站

### 公共图书馆网络

**圣彼得堡中央图书馆 (Центральная библиотека им. М.Ю. Лермонтова)**
- **地址**: ул. Чкалова, д. 48, Санкт-Петербург
- **特色**: 圣彼得堡最大的公共图书馆之一，藏书涵盖文学、历史、科学等领域。设有多个阅览室、自习室和数字资源区。定期举办读书会和文化活动。
- **开放时间**: 周一至周六 10:00–21:00
- **交通**: 地铁 Чкаловская 站

**Библиотека им. А.С. Пушкина (普希金图书馆)**
- **地址**: ул. Большая Морская, д. 65, Санкт-Петербург
- **特色**: 以俄罗斯文学巨匠普希金命名的图书馆。收藏俄语文学经典、外国文学译著和学术资料。建筑为历史建筑，内部装饰典雅。
- **开放时间**: 周二至周六 10:00–20:00
- **交通**: 地铁 Адмиралтейская 站 / Невский проспект 站

### 特色图书馆

**艾尔米塔日图书馆 (Библиотека Эрмитажа)**
- **地址**: Дворцовая пл., д. 2, Санкт-Петербург
- **特色**: 附属于艾尔米塔日博物馆的专业图书馆。收藏艺术史、考古学、历史类书籍和期刊。只对研究人员开放，普通游客无法使用。
- **开放时间**: 仅对研究人员开放，需提前申请

**圣彼得堡艺术学院图书馆 (Библиотека Академии художеств)**
- **地址**: Университетская наб., д. 17, Санкт-Петербург
- **特色**: 艺术专业图书馆，收藏绘画、雕塑、建筑、设计类书籍。面向艺术院校师生和艺术家开放。
- **开放时间**: 周一至周五 10:00–18:00

## 服务特色

### 读者卡办理
- 俄罗斯公民：护照原件
- 外国公民：护照原件
- 当日可取，有效期通常为1年

### 数字资源
- 大多数图书馆提供电子目录和数据库访问
- 部分图书馆提供WiFi和电脑使用

### 特殊服务
- 视障读者专区（有声书和盲文资料）
- 儿童专区（绘本、教育资源）
- 多媒体区（音视频资源）

## 消费提示

- 基本借阅服务通常免费
- 逾期罚款约1-5 ₽/天
- 数字资源使用免费
- 复印服务约3-10 ₽/页
