# 崩坏 3 (Honkai Impact 3rd)

> **开发商**：上海米哈游网络科技 (HoYoverse)
> **类型**：3D 动作 RPG（GaaS，老牌旗舰）
> **首发**：2016-10-14 (国服 2019-12-26)
> **平台**：PC / iOS / Android / PS4
> **数据截止**：2026-08-04（已完结主线 + 后崩坏书 + 视觉小说 + 往世乐土）

---

## 一、世界观底层

### 崩坏（Honkai）
- 周期性灾厄，伴随**律者**降世——"崩坏能极强的个体，以人类为载体"
- 核心设定：崩坏是**文明的天敌**，文明越发达崩坏越强大
- 律者核心：被击杀后可制成**神之键**或**圣遗物**

### 双纪元结构
- **前文明纪元**（约 5 万年前）：人类发展出高度文明，被终焉律者毁灭
  - 留下**逐火之蛾 / 十三英桀**、**神之键**、**月光王座**、**圣痕计划**等遗产
- **现文明纪元**（当下 2014–2018）：崩坏再次活跃，5 万年间隔

### 核心组织
- **逐火之蛾**：前文明联合国对崩坏组织，旗下"逐火十三英桀"
- **天命**：现文明欧洲最大组织，政教军商一体，主教奥托·阿波卡利斯独裁
- **逆熵**：天命北美支部独立而成的组织，对抗奥托
- **世界蛇**：凯文领导的极端反崩坏组织

### 神之键（前文明遗产）
- 第一至第十三神之键：以律者核心驱动的神兵
- 包括：虚空万藏（第一）、千界一乘（第二）、涤罪七雷（第三）、天火圣裁（第七）、羽渡尘（第八）、伊甸之星（第九）、犹大的誓约（第十一）等

### 前文明计划
- **火种计划**（华/符华）：向本世代神州传授超前知识
- **方舟计划**（格蕾修）：携带基因库离开地球寻找新家园
- **恒沙计划**（苏）：用千界一乘观测虚数之树寻找胜利世界线
- **避难所计划**（维尔薇）：冷冻休眠跨越万年
- **圣痕计划**（凯文）：人为引发崩坏筛选有圣痕潜质人类
- **监察者计划**（苏）：防止凯文失控，必要时用千界一乘封印

### 终焉之战
- 第十四律者·终焉律者降临，前文明覆灭
- 梅博士发明月光王座、使用试管婴儿技术诞下凯文之子
- 前八名战士月球决战失败，月光王座报废
- 先行者（凯文/华/苏/苍玄/丹朱）进入休眠，跨入新纪元

## 三、现文明纪元（游戏主线）

### 第一次崩坏（1952–1955）：柏林
- 第一律者·**理之律者**瓦尔特·乔伊斯诞生
- 瓦尔特牺牲，律者核心传给约阿希姆（第二代瓦尔特·杨）
- **逆熵成立**（爱因斯坦/特斯拉）

### 第二次崩坏（2000）：西伯利亚
- 巴比伦实验室人体实验诞生**第二律者·空之律者西琳**
- 齐格飞、塞西莉亚、瓦尔特·杨、奥托交锋
- 终战：齐格飞、塞西莉亚击败西琳；奥托发射崩坏裂变弹杀死塞西莉亚
- **K423 = 琪亚娜·卡斯兰娜**：奥托 422 次克隆实验后诞生，被齐格飞带走
- 奥托五百年执念：从卡莲之死开始

### 第三次崩坏（2014）：长空市
- 雷电芽衣觉醒第三律者（雷之律者）
- 琪亚娜、芽衣、布洛妮娅组成"御三家"
- 加入圣芙蕾雅学园

### 第四次崩坏（2014–2017）：大洋洲、新加坡等
- 温蒂 = 第四律者（风之律者）
- 静谧宝石（死之律者核心）事件

### 主线剧情（2016–2018+）
| 章 | 内容 |
|---|---|
| 1–9 | 御三家 + 姬子老师 + 圣芙蕾雅学园 → 月光王座、瓦尔特、幽兰黛尔 → 大崩坏 / 空之律者觉醒 / 姬子牺牲 |
| 10–12 | 量子之海、海渊城、布洛妮娅寻希儿 |
| 13–14 | 天穹市、丽塔/渡鸦、世界蛇 / 琪亚娜的"薪炎"觉醒 |
| 15–17 | 长空市 / 芽衣觉醒雷之律者 |
| 18–20 | 冰之律者、岩之律者、陨冰之律者 |
| 20–22 | **千年之羽 / 符华与识之律者**、新生的律者出现在符华体内 |
| 23–25 | **千人律者 / 支配剧场** |
| **终章（第二十五章）** | **奥托之死 / 卡莲的时刻** / 终焉律者降临 |

### 第二十六章起：第二次崩坏之后
- 终焉律者降临，地球崩坏肆虐
- 主角团分散寻找"乐土"中的十三英桀
- **爱莉希雅**的真相、始源之律者

## 五、贯穿暗线

1. **奥托的 500 年执念**：卡莲之死 → 复活她的所有努力 → 终章自我献祭
2. **琪亚娜 vs 西琳**：克隆体与原律者的灵魂之战
3. **符华的前世今生**：5 万年守护神州 → 识之律者入侵 → 仍然坚守
4. **爱莉希雅 / 始源之律者**：人类起源的律者，被伪造为第十三律者
5. **圣痕计划 / 终焉律者**：终焉的真正含义
6. **天命 / 逆熵 / 世界蛇三方博弈**

### 终章核心：奥托之死
- 奥托在天穹市使用第二神之键抵达虚数之树
- 找到了"卡莲的时刻"——一个没有崩坏的世界
- 抛弃自己的存在，让所有"如果"成为现实
- 名言："**一个人，要犯下多少恶行，才能在地狱的尽头，将她带回黎明**"

### 后崩坏书（After Honkai Odyssey）
- 终局后 8 年，崩坏被封印在月球
- 圣方丹事件、瓦尔特、芽衣成为第三小队队长
- 续作：《崩坏：星穹铁道》《绝区零》

## 六、一句话总结

> 崩坏 3 讲的是**前文明逐火之蛾对抗崩坏失败后，5 万年后的新一代继承"逐火"精神、再次面对崩坏、最终战胜终焉律者**的故事。
>
> 故事结构是 **"前文明背景 + 现文明主线"**：
> - 前文明：13 英桀 → 终焉 → 先行者休眠
> - 现文明：第二次崩坏（K423 诞生）→ 御三家 → 圣芙蕾雅 → 大崩坏 → 琪亚娜觉醒薪炎 → 千人律者 → 终章奥托献祭 → 终焉律者
>
> 核心主题：**"薪炎永燃"** —— 人类对抗命运的传承与爱。
