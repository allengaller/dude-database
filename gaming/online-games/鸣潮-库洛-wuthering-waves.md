# 鸣潮 (Wuthering Waves)

> **开发商**：广州库洛游戏（Kuro Games）
> **类型**：开放世界动作 RPG（GaaS，持续运营）
> **首发**：2024-05-23
> **平台**：PC / Android / iOS / PS5
> **数据截止**：2026-08-04（截至 3.5 版本「玄风城决战」）

---

## 一、世界观底层（所有章节的底色）

### 星球：索拉里斯（Sol-3）
- 命名致敬波兰科幻作家莱姆的《索拉里斯星》（Stanisław Lem, 1961）
- 太阳系第三颗行星，曾存在高度发达的前文明（疑为神族文明）
- 因一次浩劫留下科技断层，文明毁灭又重生

### 核心灾变：悲鸣 + 海蚀现象
- **悲鸣**：能改写物理法则的力量，索拉里斯历史上发生过两次（百年前 + 近期）
- **海蚀现象**：悲鸣对世界的侵蚀，表现为：
  - **天空海**（倒悬的异象海洋，覆盖星球天空的非物质存在）
  - **无音区**（残象诞生的摇篮，降临必伴随天空海汇聚）
  - **黑石**（灾变产物但成核心能源）
  - **残象潮**（异象生物的群体侵袭）
- **残象 → 残响 → 声骸**（战斗系统骨架）：残象被击败后留下金色「残响」，被盘古终端（葫芦）吸收后变成可重复调用的「声骸」

### 共鸣者体系
- 鸣潮子与人类结合的产物，身上有声痕
- 拥有超能力，多数带兽化特征
- 等级/分层：普通共鸣者 → 岁主（地区守护者） → 鸣式（神级）

### 核心反派：残星会
- 暗中活动，研究人类与残象融合的禁忌实验
- 2.7 版本会长亲自下场，是贯穿多章的幕后黑手
- 目的涉及"索拉里斯之外的文明"

## 二、主线三幕结构（按地区/版本推进）

> 叙事模式：**"地区巡礼 + 主题递进"**——漂泊者每到一处新地，揭开一层世界真相，同时累积自身记忆的恢复。

### ▍序章：苏醒（1.0 开篇）
**核心事件：万象新生**
- 漂泊者从沉睡中醒来，掉入索拉里斯海中
- 被秧秧、炽霞、白芷三位少女救起
- 失忆，被引至**今州城**，接触"共鸣"概念
- 遇见"无冠者"（幻象的高阶进化体），奠定战斗基调
- **主题：我是谁？**——"失忆者探索世界"的经典叙事框架

## 三、贯穿全局的暗线（彩蛋与伏笔）

库洛埋了一条很深的「漂泊者真实身份」暗线，**全剧情一直在铺垫但未完全揭底**：

1. **漂泊者不是普通人**——第一声悲鸣的亲历者、前文明遗民之一
2. **残星会会长的真实目的**——和"索拉里斯之外的文明"有关
3. **天空海的真相**——可能连接多个星球/时空，漂泊者就是从"终局"穿越天空海而来的
4. **岁主传承机制**——今汐、卡提希娅、未来的"日主"奥古斯塔、"月主"尤诺
5. **鸣式的本质**——无相燹主、利维亚坦、阿列夫一，同一层级

## 四、关键反派 / BOSS 等级

**残象强度分级**（弱→强）：**轻波级 → 巨浪级 → 怒涛级 → 海啸级 → 鸣式**

**已登场的鸣式**（最终 BOSS 级）：
- **无相燹主**（风系代表，疑似与第一声悲鸣相关）
- **利维亚坦**（2.7 大决战，七丘的"海怪"原型）
- **阿列夫一**（3.3 决战）

## 六、一句话总结

> 鸣潮的主线讲的是**一个失忆的远古存在（漂泊者），在灾变后的索拉里斯星球上，每到一个新地区揭开一层世界真相、同时找回自己身份的旅程**。
>
> 故事结构是 **「序章 + 三幕地区巡礼」**：瑝珑（重建）→ 黎那汐塔（信仰与牺牲）→ 穗波市（科技与亲情）。
>
> 暗线则是**残星会、鸣式、天空海背后的跨文明真相**——这才是最终悬念。
