# 原神 (Genshin Impact)

> **开发商**：上海米哈游网络科技 (miHoYo / HoYoverse)
> **类型**：开放世界冒险 RPG（GaaS）
> **首发**：2020-09-28
> **平台**：PC / PS5 / iOS / Android / 主机
> **数据截止**：2026-08-04（截至 5.8 版本「空月之歌」序章，纳塔主线完结，进入挪德卡莱前奏）

## 一、世界观底层

### 星球：提瓦特
虚构的七元素交汇的幻想世界，由**七种基础元素**（风/岩/雷/草/水/火/冰）驱动。人类借由对神灵的信仰获赐驱动元素的力量。

### 核心设定：天理与七神
- **天理 / 法涅斯**：提瓦特的至高神，"第一降临者"。原初巨蛋降临，延伸出四个影子（生/死/时/空四执政），击败七龙王统治提瓦特
- **七执政 / 尘世七神**：魔神战争后胜出的七位元素神，各治理一国，持有**神之心**（神座象征）
- **七龙王**：元素力之顶的原始存在，被天理击败后被夺取力量——七神的权能来自被"窃取"之力

### 核心反派：愚人众 / 深渊教团
- **愚人众**：至冬国外交使团，**冰之女皇**统御，**十一位执行官**为核心战力
  - 目的：收集七颗神之心，挑战天理/天空岛
  - 经典角色：达达利亚（公子）、女士、散兵/流浪者、队长、皮耶罗（丑角）、博士、仆人等
- **深渊教团**：非人魔物组织，与地表文明为敌
  - 创始人为**克洛达尔·亚尔伯里奇**，后由旅行者**双子之一**（空/荧）掌控
  - 目标：复国坎瑞亚，挑战天理

### 覆灭古国：坎瑞亚
- 位于地下的人类文明，无神统治（"无神的国度"）
- 500 年前因滥用深渊力量（莱茵多特的创造）触怒天理，被毁灭
- 子民受诅咒变成丘丘人
- **关键事件**：雷电真、丹朱、苍玄、大慈树王都在坎瑞亚战争中死亡

### 旅行者双子
- 世界之外的降临者（来自"虚假之天"之外）
- 在坎瑞亚被毁时与四执政之一阿斯莫德交战被封印
- 500 年后分别苏醒，一个跟随戴因斯雷布游历七国；一个成为深渊王储

## 二、主线四幕结构（按国家巡礼）

> 叙事模式：**"国家巡礼 + 元素神主题"**——每到一国揭示该国历史/神之心/被掩盖的真相，逐步拼凑天理与坎瑞亚的真相。

### 序章：风·蒙德（1.0）
- 旅行者苏醒，钓到派蒙
- 风魔龙特瓦林危机、风神温迪、解放蒙德
- 序幕：**天空岛**的暗示

### 第一章：岩·璃月（1.0–1.1）
| 幕 | 标题 | 关键事件 |
|---|---|---|
| 一 | 浮世浮生千岩间 | 请仙典仪、岩王帝君"陨落" |
| 二 | 辞行久远之躯 | 送仙典仪、钟离交出神之心 |
| 三 | 迫近的客星 | 漩涡魔神奥赛尔、神治转人治 |
| 四 | 我们终将重逢 | **与血亲短暂重逢**，戴因斯雷布登场 |

**1.1 乘霄山**：长离、菲米尼等新角色；进入深渊新层
**主题**：契约、人的觉醒、神明的退场

### 第二章：雷·稻妻（2.0–2.1）
- 锁国令、雷电将军的永恒追求
- **眼狩令 / 反抗军**冲突
- 序幕：振袖秋风问红叶
- 一幕：不动鸣神，恒常乐土
- 二幕：无念无想，泡影断灭（决战雷电将军）
- 三幕：千手百眼，天下人间（眼狩令终结）
- 四幕：回响渊底的安魂曲（间章 2.0–2.1 衔接）

**主题**：永恒的虚妄、神明与人的距离、姐姐雷电影

### 第三章：草·须弥（3.0–3.2）
- 第一幕：穿过烟帷与暗林
- 第二幕：千朵玫瑰带来的黎明
- 第三幕：迷梦与空幻与欺骗
- 第四幕：赤土之王与三朝圣者
- 第五幕：虚空鼓动，劫火高扬（**击败伪神**）
- 第六幕：卡利贝尔（3.5）
- 间章：倾落伽蓝

**核心冲突**：大贤者用虚空控制民众、草神纳西妲被囚、世界树真相、**正机之神**
**主题**：知识 vs 智慧、神明与民众的共谋

### 第四章：水·枫丹（4.0–4.2）
- 第一幕：白露与黑潮的序诗
- 第二幕：仿若无因飘落的轻雨
- 第三幕：向深水中的晨星
- 第四幕：谕示胎动的终焉之刻
- 第五幕：罪人舞步旋（**水神芙卡洛斯自我献祭**）
- 第六幕：睡前故事

**核心冲突**：枫丹人"原罪"、预言危机、水神芙宁娜的百年演技、**审判程序**与雷内
**主题**：正义的边界、神明以身殉道、真正的人类之罪

### 第五章：火·纳塔（5.0–5.3，2024–2025）
- 第一幕：荣花与炎日之途
- 第二幕：黑石湮落白石下
- 第三幕：镜与谜烟的彼方
- 第四幕：命定将焚的虹光
- 幕间：万火归一
- 第五幕：炽烈的还魂诗（5.3）
- 5.6 间章·第四幕：悖理
- 5.7 第五章第六幕：不存在时空
- 5.8 空月之歌·序章：归途

**核心冲突**：500 年前火神玛薇卡与六英雄制定的复兴计划、夜神国深渊化、六位"古名"英雄
**主题**：牺牲与传承、英雄主义的延续、反抗命运的史诗
**重大战斗**：火神玛薇卡 vs 愚人众队长"皮耶罗的同位体" / 卡皮塔诺

### 第六章：冰·至冬（未开放，预计 6.0+）
- 终章：冰之女皇、神之心集齐、决战天理
- 至冬国的"军政府"性质、七神的反抗集结

## 六、贯穿暗线

1. **空月之歌 / 挪德卡莱**：5.8 开启的新篇章，传闻与"月神"相关，是至冬前最后一个国家
2. **龙王归来**：水龙王那维莱特、草龙王阿佩普已登场，元素龙将逐步恢复权柄
3. **尼伯龙根 / 第二王座**：疑为"虚假之天"之外的真正威胁
4. **天理覆灭坎瑞亚的真相**：500 年前到底发生了什么
5. **旅行者的血亲**：为何血亲选择带领深渊而非玩家
6. **七神结局（玩家推测）**：
   - 风神：牺牲助众人登天空岛
   - 岩神：化作石像
   - 雷神：战败但执念回归
   - 水神：背刺天杰被击杀
   - 火神：燃烧自身对抗天理
   - 冰神：决战天理获胜
   - 草神：融入世界树

## 七、一句话总结

> 原神讲的是**一个来自世界之外的旅行者，跨越提瓦特七国、收集神之心、对抗天理、揭开坎瑞亚与天空岛真相**的故事。
>
> 故事结构是 **"七国巡礼 + 元素主题"**：蒙德（自由）→ 璃月（契约）→ 稻妻（永恒）→ 须弥（智慧）→ 枫丹（正义）→ 纳塔（战争）→ 至冬（反抗）。
>
> 最终主线是**"反抗天理"**——七神、愚人众、深渊、旅者各自的立场与博弈。
