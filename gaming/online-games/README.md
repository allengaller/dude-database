## 档案结构

每个游戏独立一份 `.md` 文件，统一以下结构：

1. **基础信息**：开发商、类型、首发、平台、数据截止版本
2. **世界观底层**：核心设定、力量体系、势力分布
3. **主线结构**：按"地区/版本/章节"推进
4. **关键角色**：主角、阵营领袖、反派
5. **贯穿暗线**：伏笔、悬念、待回收线索
6. **一句话总结**：核心结构 + 主题
7. **来源与参考**

## 维护策略

- **大版本更新时（X.0、X.5）**：更新对应游戏的剧情进度标注
- **年度大节点（X.Y 大版本号变化）**：补充新章节内容进"主线结构"
- **不需要每次小版本都重写**：只在剧情出现重大转折时更新

## 与 `gaming/` 上层档案库的区别

| | `gaming/` 上层 | `gaming/online-games/` |
|---|---|---|
| 范围 | 经典单机游戏（含系列）| 持续运营网游 |
| 组织 | 按年代/系列 | 按厂商/作品 |
| 内容 | 游戏概览 + 玩法 + 简史 | 剧情结构 + 世界观 + 暗线 |
| 更新频率 | 低（已完成游戏）| 高（仍在更新）|
