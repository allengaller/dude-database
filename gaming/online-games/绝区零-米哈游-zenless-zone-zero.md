# 绝区零 (Zenless Zone Zero)

> **开发商**：上海米哈游影铁科技 (HoYoverse)
> **类型**：都市动作 RPG（GaaS）
> **首发**：2024-07-04
> **平台**：PC / iOS / Android / PS5
> **数据截止**：2026-08-04（截至 2.4 版本「直到苍白荒秽之地」，罗斯凯利法 / 诺姆剧情开启）

---

## 一、世界观底层

### 核心灾变：空洞（Hollow）
- 神秘超自然灾害，凭空出现、吞噬一切
- 内部时空环境因未知效应紊乱无序
- 产生异形怪物**以骸**（分下位/上位）
- 产生高价值资源**以太**（同时也是侵蚀物质）
- **普通人进空洞 = 迷失 + 侵蚀变异 → 化为以骸**

### 末日世界设定
- 旧文明覆灭，秩序被埋葬
- 唯一幸存城市：**新艾利都**（源自苏美尔"埃利都"，人类第一座城）
- 城市依靠**开采以太资源**成为末日"奇迹之城"

### 主角设定：绳匠（法厄同）
- 官方名称"违法空洞事务调查协调人员"
- 与官方"空洞调查协会"对应的灰色职业
- **玩家扮演传奇绳匠"法厄同"**（兄妹：哲/铃）
- 通过**HDD 系统** + **邦布**进入空洞执行委托
- 名字来源：希腊神话太阳神赫利俄斯之子法厄同（驾太阳车失控坠河而死）

### 关键概念：邦布
- 玛瑟尔集团（CEO 挽昼女士）发明的小型智能设备
- 原本是空洞灾害预警装置
- 现已发展为"新艾利都的伙伴"
- **伊埃斯**：玩家 1 号助手邦布，代号"法厄同"在空洞中的"替身"

### 四大人工智能
- **Fairy（仙灵）**：主角偶然获得，数据检索/访问权限
- **Ghost（幽魂）**：入侵
- **Youkai（妖怪）**：腐化防火墙
- **Jinni（魔精）**：打包上传
- 四者合称"四把钥匙"，是某个计划的激活器

## 四、主线推进

### 序章：法厄同
- 主角账号被黑，重建绳匠账号
- 狡兔屋委托 → 抓住远景实业前掌事珀尔曼 → 获得 Fairy

- 寻找原型机，引出前社长霍尔曼
- 未知人型以骸登场，引出治安局新势力（朱鸢）
- 寻找黑客芮恩

### 第二章：维多利亚家政
- 六分街车辆故障
- 远景实业前掌事珀尔曼越狱事件
- 芭莱大厦能源中断，黑客芮恩被神秘组织控制
- **牲鬼**首度登场

### 第三章：凋零（1.4 主线）
- 长画面像"一季动画结束"
- 法厄同眼睛的"金色异变"埋下伏笔
- 兄妹找回"原本拥有的力量"

### 1.5「闪耀的此刻」
- 嘉音 + 伊芙琳的偶像剧情
- 反派"未亡人"登场

### 1.6「第一季·尾音·将眼泪与过往一同埋葬」
- 上流社会拍卖会、牲鬼秘密拍卖品
- 维多利亚家政的幕后大佬（**新艾利都市长**）登场
- 雨果（莱卡恩旧友）+ 薇薇安登场

- 11 号失踪、安比的前白银军队长身份揭露
- **轻描淡写而沉重的"反抗"**

### 1.7：反派追查
- 莱卡恩 + 雨果路线高度重合（曾搭档）
- 反舌鸟核心揭秘
- 称颂会牵涉

### 2.0「直至苍白荒秽之地」

- 飞艇遇袭
- 师姐（叶瞬光）登场 → 小光 2.0 故事核心

- **青溟剑**反噬的悲剧
- 小光加冕虚狩
- 老师/挽昼的线索进一步推进

### 2.4（最新）

- 寻找老师 + 挽昼
- 维琳娜是"天使"，挽昼大人遇袭失踪

## 六、贯穿暗线

1. **法厄同的真实身份**：兄妹的"眼睛变色"暗示非普通人，可能有"不能说"的秘密
2. **老师的下落 / 挽昼女士**：第七虚狩、邦布发明人，**进入零号空洞追寻真相**
3. **四大人工智能 + 神秘计划**：四个 AI 是某计划的"钥匙"
4. **空白的回填 - 6+4=9 个事件**："牲鬼"与旧都陷落的更深关联
5. **小光 / 仪玄 / 青溟剑**：拯救小师姐 + 师傅的感情线
6. **市长（维多利亚家政幕后大佬）** 的真实目的
7. **1.7+ 称颂会 / 反舌鸟 / TOPS 财团**：多线反派汇流

## 八、一句话总结

> 绝区零讲的是**一对兄妹绳匠"法厄同"在新艾利都经营录像店、接受绳网委托、深入空洞探险、对抗以骸并解开人类文明与空洞灾害真相**的故事。
>
> 故事结构是 **"都市群像 + 单元剧 + 暗线汇流"**：
> - 多个阵营单元剧（狡兔屋 / 维多利亚 / 对空六课 / 卡吕冬之子 / 白祇重工）作为表层
> - 老师/挽昼/旧艾利都陷落真相/四大人工智能计划作为暗线
>
> 核心主题：**"在日常中坚守的不凡"**——空洞时代下每个小人物的生存与反抗。
