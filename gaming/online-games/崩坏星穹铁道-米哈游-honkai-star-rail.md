# 崩坏：星穹铁道 (Honkai: Star Rail)

> **开发商**：上海米哈游网络科技 (HoYoverse)
> **类型**：箱庭回合制 RPG（GaaS）
> **首发**：2023-04-26
> **平台**：PC / PS5 / iOS / Android
> **数据截止**：2026-08-04（截至 3.8 版本「记忆是梦的开场白」，匹诺康尼终末任务 + 二相乐园 / 奥赫玛开启）

---

## 一、世界观底层

### 宇宙结构：星神 + 命途
- **星神**：一种已经"存在"即是"法则"的存在
- **命途**：星神所代表的哲学概念/道路，命途一旦开启就无法关闭
- 已知命途：开拓 / 智识 / 巡猎 / 毁灭 / 存护 / 虚无 / 同谐 / 丰饶 / 记忆 / 欢愉 / 均衡……
- **令使**：从命途中获取力量的最强凡人

### 虚数之树 & 量子之海
- 所有"世界"（星球/文明）都生长在**虚数之树**上
- 虚数之树与**量子之海**二元对立
- **星核**：被毁灭的星神残骸，蕴含毁灭性能量，污染一颗星球就能引发灾难

### 核心势力
- **星穹列车**：由"开拓"星神阿基维利遗留的轨道航行，阿基维利已陨落
  - 成员：姬子（领航员）/ 瓦尔特（杨，前理之律者）/ 丹恒（持明族龙尊）/ 三月七（失忆冰封少女）/ 帕姆（列车长）/ 开拓者（玩家）
- **星核猎手**：卡芙卡 / 银狼 / 刃 / 萨姆（流萤）——反派但有独立目标
- **天才俱乐部**：黑塔/螺丝咕姆/阮·梅等顶级科学家（共 83 席）
- **星际和平公司**：跨银河商业帝国，托帕&账账
- **巡海游侠**：追猎虚无令使的黄泉
- **假面愚者**：追随欢愉星神阿哈的乐子人（花火）
- **流光忆庭**：掌控记忆的特殊组织

## 二、主线叙事结构

> 模式：**"星域巡礼 + 星神主题"**——每到一颗星球解决一个星核危机，对应一种命途/星神议题。

### 第一章：黑塔空间站（1.0 序章）
- **开拓者**被卡芙卡和银狼植入星核后被星穹列车救起
- 协助黑塔空间站对抗反物质军团与"末日兽"
- 玩家加入星穹列车

### 第二章：雅利洛-VI（1.0–1.1）
**关键词：存护 / 反物质军团 / 永冬**
- 贝洛伯格永冬城、布洛妮娅、希儿、杰帕德、克拉拉
- 上下层区冲突、史瓦罗的算法、大守护者可可利亚被星核侵蚀
- **结局**：封印星核，布洛妮娅继任大守护者
- **3 月 7 日苏醒的失忆少女三月七**加入列车

### 第三章：仙舟「罗浮」（1.0–1.5）
**关键词：丰饶 / 巡猎 / 鳞渊境**
- 景元将军、符玄、停云、刃、白露、丹恒的真实身世（持明龙尊丹枫）
- **卡芙卡**故意将列车引至罗浮
- 药王秘传、幻胧（绝灭大君）危机、鳞渊境中丹恒召唤"饮月"之力
- **结局**：幻胧肉身被毁，景元受伤退居二线，符玄继任将军
- **间章**：驭空追忆、停云（活过来）、1.5 绥园浮烟、1.6 天才群星闪耀时（阮·梅）

### 第四章：匹诺康尼（2.0–2.4，"美国梦之城"）
**关键词：同谐 / 秩序 / 梦境**
- **钟表匠米哈伊尔**的邀请、"白日梦酒店"、黄金的时刻
- 列车组：姬子、瓦尔特、三月七、开拓者（丹恒留守）
- 核心冲突：
  - **砂金**（存护命途的赌徒，前公司高管）的赌局
  - **星期日**（同谐星神希佩的代言人，背叛同谐、投奔秩序）vs 列车组
  - **流萤**（星核猎手 / 萨姆的真相，"点燃大海"的怪物）
  - **知更鸟**（匹诺康尼的明星）、**加拉赫**（调酒师）
  - **米沙** = 米哈伊尔的忆域迷因（已逝先驱者）
  - **黄泉**（虚无令使，雷电·忘川守 = 芽衣/雷电的"另一个自己"）
- **2.1**：流萤梦死、黄泉登场
- **2.2**：流梦礁真相、星期日"以强制弱"vs 知更鸟"以强援弱"、谐乐大典
  - **米哈游编剧封神之作**："假结局"反转 + 三幕剧 + 星期日的秩序 vs 列车组的开拓自由
- **2.3**：匹诺康尼完结、公司谈判
- **2.4**：仙舟·星天演武仪典、飞霄将军、呼雷（步离人之主）

### 第五章：仙舟·演武仪典（2.4–2.5）
- 飞霄将军、椒丘之死、呼雷逃脱与再战
- 三月七转向巡猎命途

### 第六章：二相乐园 / 奥赫玛（3.0+）
- **翁法罗斯（奥赫玛）** 全新星域
- 命途：记忆
- 3.0 致第二次日出、换日计划
- 3.1 电子幽灵爱弥斯、爱弥斯是漂泊者养女、残星会会长现身！
- 3.2 学院暗面、绯雪登场
- 3.3 与绯雪迎战残星会、漂泊者+爱弥斯大战鸣式阿列夫一
- 3.4 联动：边缘幻梦
- 3.5 玄风城决战、大团圆、秧秧的命运
- **3.8**「记忆是梦的开场白」：匹诺康尼终末任务"橡木鸣蛀之梦"，沉没于原始忆域的美梦，**繁育**的虫鸣介入

## 五、贯穿暗线

1. **星神阿基维利之死**：列车组继承遗志
2. **开拓者体内的星核**：卡芙卡植入，"星核猎手"计划的真正目的
3. **三月七的失忆**：她是谁？和冰封的过去有什么关系？
4. **丹恒的过去**：前世丹枫（饮月之乱）
5. **星核猎手 = 卡芙卡/银狼创造开拓者**：玩家是被"反派"塑造的
6. **天外之"天外之人" / 残星会**：正在秘密集结的终极大反派
7. **3.8 引入的「繁育」虫鸣**：可能重启"虫族"主题

## 六、一句话总结

> 崩坏：星穹铁道讲的是**一个被星核猎手制造、植入星核、由星穹列车救起的"开拓者"，乘坐开拓列车穿梭于虚数之树的不同星球、对抗星核污染、结识星神命途角色**的故事。
>
> 故事结构是 **"星域巡礼 + 命途主题"**：黑塔（智识）→ 雅利洛（存护）→ 仙舟（巡猎/丰饶）→ 匹诺康尼（同谐/秩序）→ 翁法罗斯（记忆）→ 二相乐园。
>
> 核心主题是**"开拓"vs"秩序"**——自由意志 vs 铁律幸福。
