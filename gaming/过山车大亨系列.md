**行业地位**：
过山车大亨是游戏史上最成功、最具影响力的主题公园模拟经营系列。创始人Chris Sawyer使用x86汇编语言编写了前两代作品，这一技术奇迹在业界传为佳话。系列将游乐园管理的商业模拟与过山车设计的创造力工具完美结合，开创了主题公园管理模拟这一子类型。系列对后世《主题公园》《过山车之星》《Parkitect》等作品产生了深远影响。

## 编年史与核心作品

### 经典时代（1999-2004）

#### RollerCoaster Tycoon（过山车大亨）
- **开发商**：Chris Sawyer Productions
- **发行商**：Hasbro Interactive / MicroProse
- **首发日期**：1999年3月22日
- **平台**：PC (Windows) / Xbox
- **设计师**：Chris Sawyer
- **销量**：约400万份（数据来源：Atari/Hasbro历史数据）
- **核心内容**：玩家在26个预设场景中建设和管理游乐园，完成特定目标（如游客数量、公园评价、月收入）来解锁下一关。包含多种游乐设施（过山车、碰碰车、旋转木马等）、商店、景观装饰和员工管理。
- **关键设计**：**等角视角（Isometric）2D图形**；过山车轨道编辑器（高度自由的轨道设计）；游客AI（Peep）的行为模拟（饥饿、口渴、疲劳、恶心、兴奋）；色条需求系统（红色=高需求，蓝色=低需求）；财务管理系统（贷款、门票、设施定价）；员工管理（修理工、保安、清洁工、 entertainer ）
- **行业影响**：**主题公园模拟类型的开创者**。Chris Sawyer使用x86汇编语言编写游戏（为优化性能直接操作硬件）；证明了2D等角视角在1999年仍有巨大市场；过山车编辑器的自由度成为系列标志；游客AI的模拟深度影响了后世所有模拟游戏；被PC Gamer评为"史上最伟大的PC游戏之一"

#### RollerCoaster Tycoon: Corkscrew Follies / Added Attractions（过山车大亨：旋转木马大汇演 / 新增景点）
- **开发商**：Chris Sawyer Productions
- **发行商**：Hasbro Interactive
- **首发日期**：1999年11月15日（Corkscrew Follies北美）；2000年（Added Attractions欧洲）
- **平台**：PC (Windows)
- **类型**：资料片（Expansion Pack）
- **核心内容**：新增20个场景、新游乐设施（如旋转秋千、水上滑梯）、新主题区域（如古罗马、太空）。
- **行业影响**：资料片质量受到好评；新增的场景难度较高，满足了核心玩家的挑战需求

#### RollerCoaster Tycoon: Loopy Landscapes（过山车大亨：环形乐园）
- **开发商**：Chris Sawyer Productions
- **发行商**：Hasbro Interactive
- **首发日期**：2000年
- **平台**：PC (Windows)
- **类型**：资料片
- **核心内容**：新增25个场景、更多过山车类型（如倒吊式、站立式）、新地形工具。

#### RollerCoaster Tycoon 2（过山车大亨2）
- **开发商**：Chris Sawyer Productions
- **发行商**：Infogrames
- **首发日期**：2002年10月15日
- **平台**：PC (Windows)
- **设计师**：Chris Sawyer
- **销量**：原版约200万份；全版本累计超400万份
- **核心内容**：延续前作核心玩法；新增更多场景和设施；改进的过山车编辑器；更强大的地形编辑工具。
- **关键设计**：更复杂的场景编辑器；更多过山车类型和预设；改进的AI行为；更精细的财务和营销系统
- **行业影响**：Chris Sawyer再次使用汇编语言编写；被粉丝认为是系列的"集大成之作"；资料片《Time Twister》和《Wacky Worlds》扩展了时间和全球主题

#### RollerCoaster Tycoon 3（过山车大亨3）
- **开发商**：Frontier Developments
- **发行商**：Atari
- **首发日期**：2004年11月2日
- **平台**：PC (Windows) / Mac OS
- **开发商说明**：Chris Sawyer将系列交给Frontier Developments开发，自己仅担任顾问
- **销量**：约1000万份（数据来源：Frontier/Atari官方数据，截至2015年）
- **核心内容**：首次全3D化；玩家可自由旋转视角、缩放进入第一人称视角乘坐游乐设施；新增水上公园（Water Park）和野生动物园（Safari）模式。
- **关键设计**：**全3D引擎**（放弃等角视角）；CoasterCam（第一人称乘坐视角）；昼夜循环和天气系统；MixMaster（烟火和灯光秀编辑器）；水上乐园滑梯和泳池系统；野生动物园的动物管理
- **行业影响**：3D化转型成功但也引发争议（部分粉丝怀念2代的简洁）；Frontier Developments的技术实力展示；CoasterCam成为系列的标志性功能；烟火编辑器MixMaster深受玩家喜爱；资料片《Soaked!》（水上乐园）和《Wild!》（野生动物园）大幅扩展了内容

### 移动与衍生时代（2010-2016）

#### RollerCoaster Tycoon 3D（过山车大亨3D）
- **开发商**：n-Space
- **发行商**：Atari
- **首发日期**：2012年10月16日
- **平台**：Nintendo 3DS
- **销量**：约10万份
- **核心内容**：3DS平台的简化版RCT体验；触摸屏过山车编辑；StreetPass功能。
- **行业影响**：3DS平台的模拟经营尝试；但评价较差，被认为过于简化

#### RollerCoaster Tycoon 4 Mobile（过山车大亨4 移动版）
- **开发商**：On5 Apps / Pipeworks Software
- **发行商**：Atari
- **首发日期**：2014年4月10日
- **平台**：iOS / Android
- **类型**：Free-to-Play移动游戏
- **核心内容**：移动平台的简化RCT；卡通车风格；内购系统（等待时间、货币购买）。
- **行业影响**：**系列评价最低的作品**。Free-to-Play模式严重破坏游戏体验；粉丝强烈批评Atari的商业化方向；被称为"系列的耻辱"

#### RollerCoaster Tycoon World（过山车大亨世界）
- **开发商**：Nvizzio Creations / Area 52 Games / Pipeworks Software
- **发行商**：Atari
- **首发日期**：2016年11月15日
- **平台**：PC (Windows)
- **销量**：约10万份
- **核心内容**：3D主题公园建造；支持Steam Workshop；多人合作模式。
- **关键设计**：网格自由建造（Grid-free building）；3D轨道编辑器；多人合作公园建设
- **行业影响**：**与《过山车之星》的直接竞争失败**。发售后与Frontier Developments的《过山车之星》（同年11月17日发售）形成直接对比；技术问题、性能问题和UI设计受到严厉批评；被粉丝和评论家一致认为远不如《过山车之星》；Atari的品牌信誉进一步受损

#### RollerCoaster Tycoon Classic（过山车大亨 经典版）
- **开发商**：Origin8 Technologies
- **发行商**：Atari
- **首发日期**：2016年12月22日（Mobile）；2017年9月28日（PC）
- **平台**：iOS / Android / PC
- **销量**：移动端超数百万次下载
- **核心内容**：RCT1+RCT2+资料片的完整移植；触屏优化；PC版新增功能。
- **行业影响**：**对原作的忠实移植受到核心粉丝热烈欢迎**。证明了RCT1/2的经典设计经受住了时间考验；移动端的成功（iOS/Android定价$5.99）证明了付费手游仍有市场

## 精神续作与竞品

### Planet Coaster（过山车之星）
- **开发商**：Frontier Developments（原RCT3开发商）
- **首发日期**：2016年11月17日
- **平台**：PC / PS4 / PS5 / Xbox One / Xbox Series X|S
- **销量**：超2500万份（数据来源：Frontier Developments官方数据，截至2024年）
- **核心内容**：Frontier Developments脱离Atari后独立开发的RCT精神续作；3D主题公园建造；极致的视觉细节和自由度。
- **关键设计**： piece-by-piece 建造系统；高级游客AI；全球光照和天气；Steam Workshop支持；场景和过山车分享
- **行业影响**：**被广泛认为是RCT的真正继承者**。发售后与《过山车大亨世界》（2016年11月15日）的直接对比中完胜；Frontier Developments的行业地位巅峰；2022年续作《Planet Coaster 2》预告；2023年《侏罗纪世界：进化2》等Frontier其他作品也获得成功

### Parkitect
- **开发商**：Texel Raptor
- **首发日期**：2018年11月29日（正式版，2016年开启Early Access）
- **平台**：PC / Mac / Linux
- **核心内容**：向RCT1/2致敬的独立作品；等角视角2.5D风格；现代化UI和机制。
- **行业影响**：独立开发团队对经典RCT的致敬；获得核心粉丝的高度评价；Steam好评如潮

### Park Beyond（狂想乐园）
- **开发商**：Limbic Entertainment
- **首发日期**：2023年6月16日
- **平台**：PC / PS5 / Xbox Series X|S
- **核心内容**：带有叙事战役的主题公园建造；Impossification系统（将普通设施变为超现实版本）。

## 核心设计系统

### 过山车编辑器
| 代际 | 特点 |
|------|------|
| RCT1 (1999) | 2D等角视角，预设元素拼接，有限自由 |
| RCT2 (2002) | 更精细的轨道控制，更多类型 |
| RCT3 (2004) | 全3D自由建造，CoasterCam乘坐视角 |
| RCT World (2016) | 网格自由建造，3D编辑器 |

### 游客AI（Peep）系统
- **基本需求**：饥饿、口渴、厕所、疲劳、恶心、兴奋
- **行为模拟**：根据设施刺激度（Intensity）、恶心度（Nausea）选择是否乘坐
- **财务行为**：根据公园评价和收入决定消费意愿
- **情绪反馈**： happiness 、愤怒、迷路、需要洗手间等状态

### 员工管理系统
| 员工类型 | 功能 |
|----------|------|
| **Handyman（清洁工）** | 清理垃圾、除草、浇水 |
| **Mechanic（修理工）** | 维修设施、检查安全 |
| **Security Guard（保安）** | 维持秩序、阻止破坏 |
| **Entertainer（ entertainer ）** | 穿着吉祥物服装娱乐游客 |
