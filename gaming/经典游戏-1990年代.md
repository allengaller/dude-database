# 1990年代经典游戏数据库（数据截止：2026年4月）

**数据说明**：本数据库收录1990年代（1990-1999）发行的具有行业里程碑意义的电子游戏作品，按游戏行业专业标准整理。1990年代是3D图形革命、CD-ROM媒介普及和主机市场格局重塑的关键时期。

---

## 行业概述

1990年代是电子游戏产业从2D向3D转型的决定性十年。1994年索尼PlayStation和世嘉Saturn开启32位主机时代，1996年任天堂64带来真正的3D平台游戏革命。CD-ROM媒介使全动态影像（FMV）、配音和大型游戏成为可能。PC平台迎来DOOM、魔兽争霸等里程碑作品，第一人称射击（FPS）和即时战略（RTS）两大类型在此年代成熟。

**关键数据**：
- 1990年代全球游戏市场规模从约150亿美元增长至约300亿美元（数据来源：Newzoo《全球游戏市场报告》历史回溯数据）
- PlayStation（1994年）成为首款销量破亿的家用主机（数据来源：索尼互动娱乐官方销售数据）
- 1990年代发行的游戏中，超过30款入选IGN「史上最伟大的100款游戏」（数据来源：IGN editorial, 2023版）

## 1990年

### Super Mario World（超级马里奥世界）
- **中文名**：超级马里奥世界
- **开发商**：Nintendo EAD
- **发行商**：Nintendo
- **首发平台**：Super Nintendo Entertainment System (SNES)
- **首发日期**：1990年11月21日（日本）；1991年8月23日（北美）
- **游戏类型**：平台跳跃
- **历史销量**：SNES版约2061万份（数据来源：任天堂官方销售数据，截至2024年3月）
- **游戏简介**：马里奥与路易吉前往恐龙岛拯救碧奇公主，首次引入耀西（Yoshi）作为可骑乘伙伴。
- **行业影响**：SNES首发护航大作；2D平台跳跃游戏的集大成之作；耀西角色的引入极大丰富了系列玩法；秘密关卡和隐藏出口的设计树立了探索性平台游戏的标杆。

### The Secret of Monkey Island（猴岛小英雄）
- **中文名**：猴岛小英雄
- **开发商**：Lucasfilm Games
- **发行商**：Lucasfilm Games
- **首发平台**：PC (MS-DOS) / Amiga / Atari ST
- **首发日期**：1990年10月
- **游戏类型**：点击式冒险（Point-and-Click Adventure）
- **行业影响**：LucasArts冒险游戏的巅峰之作；Guybrush Threepwood成为冒险游戏标志性角色；幽默叙事和游戏设计的完美结合；"侮辱剑斗"（Insult Swordfighting）系统成为游戏史经典机制；取消死亡和死胡同的设计革新了冒险游戏体验。

### Wing Commander（银河飞将）
- **中文名**：银河飞将
- **开发商**：Origin Systems
- **发行商**：Origin Systems
- **首发平台**：PC (MS-DOS)
- **首发日期**：1990年9月
- **游戏类型**：太空战斗模拟
- **行业影响**：Chris Roberts（《星际公民》创始人）的开山之作；将电影化叙事融入太空模拟游戏；多分支任务结构根据玩家表现动态调整；证明了PC平台可承载高端视听体验。

## 1991年

### Sonic the Hedgehog（刺猬索尼克）
- **中文名**：刺猬索尼克
- **开发商**：Sonic Team
- **发行商**：SEGA
- **首发平台**：SEGA Mega Drive / Genesis
- **首发日期**：1991年6月23日
- **游戏类型**：平台跳跃
- **历史销量**：Mega Drive版约1500万份（数据来源：世嘉官方历史数据）
- **游戏简介**：蓝色刺猬索尼克以超音速穿越关卡，收集金环，击败邪恶的蛋头博士（Dr. Robotnik）。
- **行业影响**：**世嘉的标志性IP和任天堂马里奥的直接竞争对手**；以"速度感"为核心差异化，与马里奥的"精确跳跃"形成鲜明对比；成为1990年代世嘉企业形象的化身；全球累计销量超14亿份（全系列，数据来源：世嘉2024年财报）。

### Street Fighter II（街头霸王2）
- **中文名**：街头霸王2
- **开发商**：Capcom
- **发行商**：Capcom
- **首发平台**：街机 / SNES
- **首发日期**：1991年2月（街机CPS）；1992年6月（SNES）
- **游戏类型**：格斗（Fighting）
- **历史销量**：SNES版约630万份；街机收入约100亿日元（数据来源：Capcom官方销售数据）
- **游戏简介**：8名来自世界各地的格斗家参加世界格斗大赛，每名角色拥有独特的招式和背景故事。
- **行业影响**：**格斗游戏历史上最重要的作品**。开创了现代格斗游戏的基本框架（血条、时间限制、连招系统、特殊技指令输入）；定义了"六键格斗"标准；催生了全球电子竞技的雏形（街机厅对战文化）；衍生出无数模仿者和进化者；Capcom最畅销的街机游戏。

## 1992年

### Wolfenstein 3D（德军总部3D）
- **中文名**：德军总部3D
- **开发商**：id Software
- **发行商**：Apogee Software / id Software
- **首发平台**：PC (MS-DOS) / SNES
- **首发日期**：1992年5月5日
- **游戏类型**：第一人称射击（FPS）
- **行业影响**：**现代FPS类型的奠基之作**。John Carmack的射线投射引擎（Ray Casting Engine）开创了伪3D游戏时代；证明了PC可作为动作游戏的主流平台；为1993年《DOOM》的诞生铺平道路；引入了 health pack、弹药管理和秘密区域等FPS标配机制。

### Mortal Kombat（真人快打）
- **中文名**：真人快打
- **开发商**：Midway Games
- **发行商**：Midway / Acclaim
- **首发平台**：街机 / 多平台家用机
- **首发日期**：1992年10月8日（街机）
- **游戏类型**：格斗（Fighting）
- **行业影响**：**引发美国国会听证会并催生ESRB评级制度的游戏**。以真人动作捕捉和血腥终结技（Fatality）闻名；与《街头霸王2》共同推动格斗游戏黄金时代；直接导致了娱乐软件分级委员会（ESRB）于1994年成立；成为1990年代最具争议的流行文化符号。

### Dune II（沙丘2）
- **中文名**：沙丘2
- **开发商**：Westwood Studios
- **发行商**：Virgin Games
- **首发平台**：PC (MS-DOS) / Amiga
- **首发日期**：1992年
- **游戏类型**：即时战略（RTS）
- **行业影响**：**现代即时战略游戏类型的开创者**。引入了基地建造、资源采集（香料）、科技树和单位生产队列；鼠标框选多单位的设计成为RTS标配；直接启发了《命令与征服》和《魔兽争霸》系列；对电子竞技和战略游戏产业产生革命性影响。

### Alone in the Dark（鬼屋魔影）
- **中文名**：鬼屋魔影
- **开发商**：Infogrames
- **发行商**：Infogrames / Interplay
- **首发平台**：PC (MS-DOS) / PC-98 / FM Towns
- **首发日期**：1992年
- **游戏类型**：生存恐怖（Survival Horror）
- **行业影响**：**生存恐怖游戏类型的真正开创者**（早于《生化危机》3年）。使用多边形角色和预渲染背景的结合；固定摄像机视角和坦克式移动；受H.P. Lovecraft作品启发的恐怖叙事；直接影响了《生化危机》《寂静岭》等后世作品。

## 1993年

### DOOM（毁灭战士）
- **中文名**：毁灭战士
- **开发商**：id Software
- **发行商**：id Software
- **首发平台**：PC (MS-DOS)
- **首发日期**：1993年12月10日
- **游戏类型**：第一人称射击（FPS）
- **历史销量**：约350万份（数据来源：id Software历史数据）； shareware版本估计分发超1000万份
- **游戏简介**：玩家扮演太空陆战队员，在火星卫星基地与地狱恶魔大军作战。
- **行业影响**：**FPS游戏历史上最重要的作品**。John Carmack的DOOM引擎实现了真正的纹理映射3D环境；引入死亡竞赛（Deathmatch）多人联机模式；催生了在线多人游戏文化；推动了PC硬件（尤其是显卡）的升级需求；被NASA安装在国际空间站；被大量学术机构研究其技术和社会影响；2024年新作《DOOM: The Dark Ages》仍在延续系列传奇。

### Myst（神秘岛）
- **中文名**：神秘岛
- **开发商**：Cyan Worlds
- **发行商**：Broderbund / Midway
- **首发平台**：Mac OS / PC (Windows)
- **首发日期**：1993年9月24日
- **游戏类型**：冒险 / 解谜（Adventure / Puzzle）
