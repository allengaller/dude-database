# RollerCoaster Tycoon（过山车大亨）

- **中文名**：过山车大亨
- **开发商**：Chris Sawyer Productions
- **发行商**：Hasbro Interactive
- **首发平台**：PC (Windows)
- **首发日期**：1999年3月22日
- **游戏类型**：模拟 / 经营（Simulation / Management）
- **历史销量**：约400万份（数据来源：Atari/Hasbro历史数据）
- **游戏简介**：玩家设计、建造并管理游乐园，特别关注过山车等游乐设施的设计和运营。
- **行业影响**：**详见 [gaming-series-rollercoaster-tycoon.md](gaming-series-rollercoaster-tycoon.md)**。Chris Sawyer使用x86汇编语言编写的编程奇迹；等角视角的游乐园模拟巅峰； coaster design 系统的深度和真实物理模拟；游客AI（Peep）的行为模拟；开创了主题公园管理模拟子类型；2004年续作《过山车大亨3》引入全3D视角。
