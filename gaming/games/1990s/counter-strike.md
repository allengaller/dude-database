# Counter-Strike（反恐精英）

- **中文名**：反恐精英
- **开发商**：Valve Corporation / Minh "Gooseman" Le, Jess Cliffe
- **发行商**：Valve Corporation / Sierra On-Line
- **首发平台**：PC (Windows)
- **首发日期**：1999年6月19日（Mod版）；2000年11月（零售版）
- **游戏类型**：第一人称射击 / 战术射击（Tactical FPS）
- **行业影响**：**起源于《半条命》Mod，成为史上最成功的多人FPS之一**。反恐精英（CT）与恐怖分子（T）的5v5对抗；经济系统（购买武器）和回合制设计；de_dust2等地图成为电竞文化符号；催生了全球职业电竞生态（如ESL、DreamHack）；CS 1.6成为2000年代网吧标配；CS:GO（2012年）和CS2（2023年）延续传奇；Steam平台用户基数的核心驱动力之一。
