# Tony Hawk's Pro Skater（托尼·霍克职业滑板）

- **中文名**：托尼·霍克职业滑板
- **开发商**：Neversoft
- **发行商**：Activision
- **首发平台**：PlayStation / Nintendo 64 / Dreamcast / PC
- **首发日期**：1999年9月29日
- **游戏类型**：体育 / 滑板模拟（Sports / Skateboarding）
- **历史销量**：约300万份（数据来源：Activision历史数据）
- **游戏影响**：将滑板运动游戏化的巅峰之作；精确的操控手感和combo连击系统； Punk Rock / Ska 音乐原声成为文化标志；推动了滑板运动在主流文化中的普及；系列累计销量超3000万份（数据来源：Activision 2020年财报）。
