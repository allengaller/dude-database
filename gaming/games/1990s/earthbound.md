# EarthBound（地球冒险）

- **中文名**：地球冒险 / MOTHER 2
- **开发商**：Ape Inc. / HAL Laboratory
- **发行商**：Nintendo
- **首发平台**：SNES
- **首发日期**：1994年8月27日（日本）；1995年6月5日（北美）
- **游戏类型**：角色扮演（JRPG）
- **行业影响**：糸井重里（Shigesato Itoi）编剧的现代背景JRPG；以当代美国小镇为舞台的反传统设定；超现实主义幽默和深刻情感叙事的独特结合；尽管在发售初期销量一般，后成为游戏 cult classic 的代表；对《Undertale》等独立游戏产生深远影响。
