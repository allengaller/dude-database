# Pokémon Red / Green（宝可梦 红/绿）

- **中文名**：宝可梦 红/绿（日本）/ 红/蓝（国际版）
- **开发商**：Game Freak
- **发行商**：Nintendo
- **首发平台**：Game Boy
- **首发日期**：1996年2月27日（日本）；1998年9月（北美"红/蓝"版）
- **游戏类型**：角色扮演 / 收集（RPG / Collection）
- **历史销量**：Game Boy版约3100万份（红/蓝合计，数据来源：任天堂官方销售数据）
- **游戏简介**：玩家在关都地区捕捉、训练宝可梦，挑战8大道馆和宝可梦联盟，最终成为宝可梦大师。
- **行业影响**：**人类历史上最成功的跨媒体IP之一**。田尻智（Satoshi Tajiri）的昆虫收集童年梦想的产物；交换和对战的社交设计革命性地利用了Game Boy的连线功能；衍生出动画、卡牌游戏、电影、周边商品等庞大产业链；全球累计收入超1000亿美元（数据来源：Statista《Highest Grossing Media Franchises》2024）；成为任天堂最核心的IP之一。
