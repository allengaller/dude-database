# Star Fox 64（星际火狐64 / Lylat Wars）

- **中文名**：星际火狐64
- **开发商**：Nintendo EAD
- **发行商**：Nintendo
- **首发平台**：Nintendo 64
- **首发日期**：1997年4月27日（日本）；1997年6月30日（北美）
- **游戏类型**：轨道射击 / 飞行模拟
- **历史销量**：N64版约400万份（数据来源：任天堂官方销售数据）
- **游戏简介**：狐狸飞行员福克斯·麦克劳德（Fox McCloud）带领星际火狐战队对抗安德罗斯（Andross）。
- **行业影响**：N64 Rumble Pak（震动包）的首发配套游戏，开创了手柄力反馈的先河；全语音配音（N64平台罕见）；分支路线和多结局设计；Rail Shooter类型的家用机巅峰；Team Star Fox角色成为任天堂二线IP的代表。
