# System Shock（网络奇兵）

- **中文名**：网络奇兵
- **开发商**：LookingGlass Technologies
- **发行商**：Origin Systems
- **首发平台**：PC (MS-DOS)
- **首发日期**：1994年9月
- **游戏类型**：第一人称动作角色扮演 / 沉浸式模拟（Immersive Sim）
- **行业影响**：**沉浸式模拟（Immersive Sim）类型的开创者**。Ken Levine的早期作品；SHODAN成为游戏史上最经典的AI反派之一；将FPS与RPG元素（升级、黑客、探索）深度结合；对《生化奇兵》《掠食》《杀出重围》等后世作品产生直接影响。
