# Mortal Kombat（真人快打）

- **中文名**：真人快打
- **开发商**：Midway Games
- **发行商**：Midway / Acclaim
- **首发平台**：街机 / 多平台家用机
- **首发日期**：1992年10月8日（街机）
- **游戏类型**：格斗（Fighting）
- **行业影响**：**引发美国国会听证会并催生ESRB评级制度的游戏**。以真人动作捕捉和血腥终结技（Fatality）闻名；与《街头霸王2》共同推动格斗游戏黄金时代；直接导致了娱乐软件分级委员会（ESRB）于1994年成立；成为1990年代最具争议的流行文化符号。
