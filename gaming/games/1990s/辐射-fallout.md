# Fallout（辐射）

- **中文名**：辐射
- **开发商**：Interplay Entertainment
- **发行商**：Interplay Entertainment
- **首发平台**：PC (Windows / MS-DOS)
- **首发日期**：1997年9月30日
- **游戏类型**：角色扮演（CRPG）
- **历史销量**：约60万份（数据来源：Interplay历史数据）
- **游戏简介**：核战后的废土世界，主角"避难所居民"离开13号避难所寻找净水芯片，最终面对超级变种人军队。
- **行业影响**：**后启示录题材RPG的标杆**。S.P.E.C.I.A.L.属性系统；黑色幽默和道德选择的深度叙事；回合制战斗与行动点（AP）系统；对《废土》等后世作品和Bethesda《辐射3/4/76》系列产生直接影响；cult classic 地位使其在2010年代被Bethesda复活后成为全球主流IP。
