# Another World（另一个世界 / 异世界）

- **中文名**：另一个世界
- **开发商**：Delphine Software
- **发行商**：Delphine Software / Interplay
- **首发平台**：Amiga / Atari ST
- **首发日期**：1991年
- **游戏类型**：动作冒险 / 电影化平台
- **行业影响**：Éric Chahi一人独立开发；极简叙事（无文字、无HUD）的电影化表达；引入上下文敏感的交互系统；对《ICO》《 limbo》等后世独立游戏产生深远影响。

## 数据来源说明

*本数据库基于以下公开可查的权威来源整理：*

- **Blizzard Entertainment官方数据**：战网平台历史统计（截至2024年）
- **Valve Corporation官方数据**：Steam平台历史销售数据
