# Myst（神秘岛）

- **中文名**：神秘岛
- **开发商**：Cyan Worlds
- **发行商**：Broderbund / Midway
- **首发平台**：Mac OS / PC (Windows)
- **首发日期**：1993年9月24日
- **游戏类型**：冒险 / 解谜（Adventure / Puzzle）
- **历史销量**：PC/Mac版累计超600万份（数据来源：Cyan Worlds官方统计，1990年代最畅销PC游戏）
- **行业影响**：**CD-ROM时代的标志性作品**。预渲染3D图形和高品质音轨展示了CD-ROM媒介的潜力；成为PC游戏吸引主流非玩家用户的现象级作品；极简的点击式探索与复杂谜题的结合；对《见证者》《Gone Home》等后世探索类游戏产生影响。
