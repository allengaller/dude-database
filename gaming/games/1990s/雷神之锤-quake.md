# Quake（雷神之锤）

- **中文名**：雷神之锤
- **开发商**：id Software
- **发行商**：GT Interactive
- **首发平台**：PC (MS-DOS / Windows)
- **首发日期**：1996年6月22日
- **游戏类型**：第一人称射击（FPS）
- **历史销量**：约110万份（数据来源：id Software历史数据）
- **游戏简介**：玩家穿越多个维度与远古敌人战斗，最终击败夏塔克（Shub-Niggurath）。
- **行业影响**：**第一款真正的全3D实时渲染FPS**。John Carmack的Quake引擎实现了真正的3D多边形环境（非DOOM的2.5D）；推动了3D加速显卡（3dfx Voodoo等）的普及；QuakeWorld在线多人模式成为早期电竞的基石；催生了mod文化（Team Fortress起源于Quake mod）；对Valve《半条命》引擎产生直接影响。
