# Clair Obscur: Expedition 33（光与影：33号远征队）

- **中文名**：光与影：33号远征队
- **开发商**：Sandfall Interactive
- **发行商**：Sandfall Interactive / Kepler Interactive
- **首发平台**：PC / PlayStation 5 / Xbox Series X|S
- **首发日期**：2025年4月24日
- **游戏类型**：回合制角色扮演 / 动作
- **Metacritic评分**：92/000 (PC) / 92/000 (PS5) / 91/000 (XSX)
- **历史销量**：发售首周超100万份（数据来源：Sandfall Interactive官方数据）
- **游戏简介**：33号远征队的成员踏上消灭"绘母"（Paintress）的旅程，每次远征的编号递减，象征生命的倒计时。
- **行业影响**：**2025年最大黑马**。法国工作室Sandfall Interactive的首部作品；回合制+QTE即时动作的创新战斗系统；法国美好年代（Belle Époque）美术风格；Lóránt Deutsch配音和音乐；2025年TGA年度游戏有力竞争者；独立工作室（约30人）创造3A质量作品的典范。
