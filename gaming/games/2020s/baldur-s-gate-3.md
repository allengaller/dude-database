# Baldur's Gate 3（博德之门3）

- **中文名**：博德之门3
- **开发商**：Larian Studios
- **发行商**：Larian Studios
- **首发平台**：PC / PlayStation 5 / Xbox Series X|S
- **首发日期**：2023年8月3日（PC正式版，2020年10月开启Early Access）
- **游戏类型**：角色扮演 / 回合制策略（CRPG）
- **Metacritic评分**：96/000 (PC) / 96/000 (PS5) / 96/000 (XSX)
- **历史销量**：超1500万份（数据来源：Larian Studios官方数据，截至2024年）
- **游戏简介**：被夺心魔蝌蚪感染的冒险者在费伦大陆寻找治愈方法，卷入吉斯洋基人和夺心魔帝国的冲突。
- **行业影响**：**CRPG的复兴与巅峰**。基于龙与地下城5版规则；电影化表演（动捕+全语音）与深度CRPG系统的结合；极高的玩家自由度（17,000种结局变化，数据来源：Larian Studios）；角色恋爱和同伴系统的深度；2023年TGA年度游戏、最佳角色扮演游戏、最佳叙事游戏、最佳表演（Neil Newbon饰Astarion）、玩家之声；2024年Steam年度游戏；推动了CRPG从 niche 走向主流。
