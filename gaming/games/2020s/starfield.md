# Starfield（星空）

- **中文名**：星空
- **开发商**：Bethesda Game Studios
- **发行商**：Bethesda Softworks / Xbox Game Studios
- **首发平台**：PC / Xbox Series X|S
- **首发日期**：2023年9月6日
- **游戏类型**：开放世界 / 动作角色扮演 / 太空
- **Metacritic评分**：83/000 (PC) / 83/000 (XSX)
- **历史销量**：超1500万份玩家（数据来源：Microsoft官方数据，截至2024年，含Game Pass用户）
- **行业影响**：Bethesda 25年来的首个新IP。Creation Engine 2的技术展示；1000颗可探索星球（程序生成与手工设计混合）；飞船建造和改装系统；Constellation组织的太空探索叙事；Xbox Game Studios的旗舰独占；2023年TGA最佳角色扮演游戏提名；2024年DLC《破碎空间》（Shattered Space）发售。
