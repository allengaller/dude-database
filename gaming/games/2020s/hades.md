# Hades（哈迪斯）

- **中文名**：哈迪斯
- **开发商**：Supergiant Games
- **发行商**：Supergiant Games
- **首发平台**：Nintendo Switch / PC
- **首发日期**：2020年9月17日（正式版，2018年12月开启Early Access）
- **游戏类型**：Roguelike / 动作 / 角色扮演
- **Metacritic评分**：93/100 (Switch) / 93/100 (PC) / 93/100 (PS4) / 93/100 (XONE)
- **历史销量**：约1000万份（数据来源：Supergiant Games官方数据，截至2024年）
- **游戏简介**：冥王哈迪斯之子扎格列欧斯（Zagreus）试图逃离冥界，在每次死亡后与众神亲属互动并推进剧情。
- **行业影响**：**Roguelike叙事的革命**。将程序生成的Roguelike玩法与持续叙事完美结合；每次死亡后推进剧情的Boon系统；希腊神话的现代重构（Logan Cunningham配音）；2020年TGA年度独立游戏、最佳动作游戏、最佳叙事游戏提名；Supergiant Games的第四款作品也是商业巅峰；2024年续作《Hades II》开启Early Access。
