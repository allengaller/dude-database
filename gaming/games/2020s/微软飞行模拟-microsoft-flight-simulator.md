# Microsoft Flight Simulator（微软飞行模拟）

- **中文名**：微软飞行模拟
- **开发商**：Asobo Studio
- **发行商**：Xbox Game Studios
- **首发平台**：PC / Xbox Series X|S
- **首发日期**：2020年8月18日
- **游戏类型**：飞行模拟
- **Metacritic评分**：91/100 (PC)
- **行业影响**：**模拟游戏的技术奇迹**。基于Bing Maps卫星数据和Azure AI的程序化生成地球；1:1比例的真实地球可飞行；实时天气和空中交通数据整合；2020年TGA最佳模拟/策略游戏；2021年Xbox Series X|S版；2024年《微软飞行模拟2024》进一步升级。
