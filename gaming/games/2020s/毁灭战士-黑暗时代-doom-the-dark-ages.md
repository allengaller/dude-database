# Doom: The Dark Ages（毁灭战士：黑暗时代）

- **中文名**：毁灭战士：黑暗时代
- **开发商**：id Software
- **发行商**：Bethesda Softworks / Xbox Game Studios
- **首发平台**：PC / PlayStation 5 / Xbox Series X|S
- **首发日期**：2025年5月15日
- **游戏类型**：第一人称射击（FPS）
- **Metacritic评分**：86/000 (PC) / 86/000 (PS5) / 86/000 (XSX)
- **历史销量**：发售首周表现强劲（具体数据待公布）
