# Stray（迷失）

- **中文名**：迷失
- **开发商**：BlueTwelve Studio
- **发行商**：Annapurna Interactive
- **首发平台**：PlayStation 4 / PlayStation 5 / PC
- **首发日期**：2022年7月19日
- **游戏类型**：冒险 / 解谜 / 第三人称
- **Metacritic评分**：83/000 (PS5) / 83/000 (PC)
- **历史销量**：超500万份（数据来源：Annapurna Interactive官方数据，截至2024年）
- **游戏简介**：一只橘猫在赛博朋克风格的废弃城市中探索，与小型无人机B-12合作寻找回家之路。
- **行业影响**：**猫咪主角的 viral 现象**。以猫咪视角的沉浸体验；没有对话的叙事设计；赛博朋克与猫的反差萌；2022年TGA最佳 debut 独立游戏、最佳独立游戏；被大量玩家评为"年度最治愈游戏"；2024年宣布将改编为动画电影。
