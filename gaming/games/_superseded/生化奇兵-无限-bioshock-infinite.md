# BioShock Infinite（生化奇兵：无限）

- **中文名**：生化奇兵：无限
- **开发商**：Irrational Games
- **发行商**：2K Games
- **首发平台**：PC / PlayStation 3 / Xbox 360
- **首发日期**：2013年3月26日
- **游戏类型**：第一人称射击 / 沉浸式模拟
- **Metacritic评分**：94/100 (PC) / 94/100 (PS3) / 93/100 (X360)
- **历史销量**：约1170万份（数据来源：Take-Two Interactive官方销售数据，截至2023年）
- **游戏简介**：私家侦探Booker DeWitt前往天空之城Columbia营救Elizabeth，揭开多重宇宙和命运循环的真相。
- **行业影响**：叙事深度的FPS标杆。Ken Levine的导演巅峰；Elizabeth的AI伙伴设计（最可信的NPC之一）；Sky-Hook和Vigors的战斗系统；哥伦比亚的种族主义和民粹主义政治隐喻；结局的多重宇宙反转成为游戏史最著名叙事转折之一；2014年DLC《Burial at Sea》与《生化奇兵》原作宇宙连接。
