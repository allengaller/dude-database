# DOOM（毁灭战士）

- **中文名**：毁灭战士
- **开发商**：id Software
- **发行商**：id Software
- **首发平台**：PC (MS-DOS)
- **首发日期**：1993年12月10日
- **游戏类型**：第一人称射击（FPS）
- **历史销量**：约350万份（数据来源：id Software历史数据）； shareware版本估计分发超1000万份
- **游戏简介**：玩家扮演太空陆战队员，在火星卫星基地与地狱恶魔大军作战。
- **行业影响**：**FPS游戏历史上最重要的作品**。John Carmack的DOOM引擎实现了真正的纹理映射3D环境；引入死亡竞赛（Deathmatch）多人联机模式；催生了在线多人游戏文化；推动了PC硬件（尤其是显卡）的升级需求；被NASA安装在国际空间站；被大量学术机构研究其技术和社会影响；2024年新作《DOOM: The Dark Ages》仍在延续系列传奇。
