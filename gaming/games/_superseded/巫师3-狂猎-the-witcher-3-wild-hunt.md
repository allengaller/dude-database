# The Witcher 3: Wild Hunt（巫师3：狂猎）

- **中文名**：巫师3：狂猎
- **开发商**：CD Projekt Red
- **发行商**：CD Projekt / Warner Bros. / Bandai Namco / Spike Chunsoft
- **首发平台**：PC / PlayStation 4 / Xbox One
- **首发日期**：2015年5月19日
- **游戏类型**：开放世界 / 动作角色扮演
- **Metacritic评分**：93/100 (PC) / 92/100 (PS4) / 91/100 (XONE)
- **历史销量**：全平台累计超5000万份（数据来源：CD Projekt Red官方销售数据，截至2023年）
- **游戏简介**：猎魔人杰洛特（Geralt of Rivia）寻找养女希里（Ciri），在战乱的大陆上做出影响世界命运的抉择。
- **行业影响**：**开放世界叙事设计的里程碑**。基于Andrzej Sapkowski小说的东欧奇幻巅峰； side quest 的质量堪比主线任务（如"血腥男爵"故事弧）；开放世界细节密度（Gwent卡牌、怪物图鉴、民间传说）；两个大型DLC《石之心》和《血与酒》（被大量玩家认为质量超过本体）；2019年Netflix电视剧改编（亨利·卡维尔主演）；2023年次世代更新版；CD Projekt Red的行业地位巅峰。
