# Hogwarts Legacy（霍格沃茨之遗）

- **中文名**：霍格沃茨之遗
- **开发商**：Avalanche Software
- **发行商**：Warner Bros. Games
- **首发平台**：PC / PlayStation 5 / Xbox Series X|S / PlayStation 4 / Xbox One / Nintendo Switch
- **首发日期**：2023年2月10日（PC/PS5/XSX）；2023年5月5日（PS4/XONE）；2023年11月14日（Switch）
- **游戏类型**：开放世界 / 动作角色扮演
- **Metacritic评分**：83/000 (PC) / 84/000 (PS5) / 85/000 (XSX)
- **历史销量**：约3000万份（数据来源：Warner Bros.官方数据，截至2024年）
- **行业影响**：**哈利·波特IP游戏的历史性成功**。霍格沃茨城堡的沉浸式探索；1800年代魔法世界的原创故事（避开原著主要角色争议）；魔法咒语组合战斗系统；发售两周收入超8.5亿美元（数据来源：Warner Bros.新闻稿）；成为2023年最畅销游戏之一；Switch版的技术妥协引发讨论。
