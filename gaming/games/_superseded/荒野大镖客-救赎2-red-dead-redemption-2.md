# Red Dead Redemption 2（荒野大镖客：救赎2）

- **中文名**：荒野大镖客：救赎2
- **开发商**：Rockstar Studios
- **发行商**：Rockstar Games
- **首发平台**：PlayStation 4 / Xbox One / PC
- **首发日期**：2018年10月26日
- **游戏类型**：开放世界 / 动作冒险
- **Metacritic评分**：97/100 (PS4) / 97/100 (XONE) / 93/100 (PC)
- **历史销量**：约6500万份（数据来源：Take-Two Interactive官方销售数据，截至2024年）
- **游戏简介**：范德林德帮派成员亚瑟·摩根（Arthur Morgan）在1899年美国西部末期经历帮派的衰落和个人的救赎。
- **行业影响**：**开放世界沉浸感的巅峰**。Euphoria物理引擎和动物生态系统的极致细节；Arthur Morgan的角色弧和Roger Clark的表演；Honor系统和多结局；狩猎、钓鱼、营地管理的生存元素；Red Dead Online的GaaS模式；发售首周末收入超7.25亿美元（数据来源：Take-Two新闻稿）；被大量媒体评为2018年年度游戏。
