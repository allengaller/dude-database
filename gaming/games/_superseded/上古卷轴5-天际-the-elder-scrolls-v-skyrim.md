# The Elder Scrolls V: Skyrim（上古卷轴5：天际）

- **中文名**：上古卷轴5：天际
- **开发商**：Bethesda Game Studios
- **发行商**：Bethesda Softworks
- **首发平台**：PC / PlayStation 3 / Xbox 360
- **首发日期**：2011年11月11日
- **游戏类型**：开放世界 / 动作角色扮演
- **Metacritic评分**：94/100 (PC) / 92/100 (PS3) / 96/100 (X360)
- **历史销量**：全平台累计超6000万份（数据来源：Bethesda/Todd Howard公开声明，2023年）
- **游戏简介**：龙裔（Dragonborn）在的天际省探索、战斗、学习龙语，最终阻止世界吞噬者奥杜因（Alduin）毁灭世界。
- **行业影响**：**开放世界RPG的范式确立者**。Radiant Story系统实现动态任务生成；Mod社区（Nexus Mods超10万款Mod）延长了游戏寿命超过10年；"直到你 knees 中了一箭"等台词成为流行文化梗；多次跨世代移植（PS3/PS4/PS5/Switch/VR）；2016年《天际 特别版》、2021年《天际 周年纪念版》持续发售。
