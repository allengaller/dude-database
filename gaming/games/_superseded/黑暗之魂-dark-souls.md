# Dark Souls（黑暗之魂）

- **中文名**：黑暗之魂
- **开发商**：FromSoftware
- **发行商**：Namco Bandai Games / Atlus（北美）
- **首发平台**：PlayStation 3 / Xbox 360 / PC
- **首发日期**：2011年9月22日（日本PS3/X360）；2011年10月4日（北美）；2012年8月24日（PC）
- **游戏类型**：动作角色扮演（Action RPG / "Soulslike"）
- **Metacritic评分**：89/100 (PS3) / 89/100 (X360) / 85/100 (PC)
- **历史销量**：约270万份（数据来源：Bandai Namco官方销售数据，截至2013年）；全系列累计超2700万份
- **游戏简介**：玩家在罗德兰（Lordran）探索 interconnected 世界，收集 Lords' Souls，最终选择点燃或熄灭初火（First Flame）。
- **行业影响**：**"Soulslike"子类型的开创者**。宫崎英高（Hidetaka Miyazaki）的突破性作品；高难度但公平的战斗设计；环境叙事（Item Descriptions讲述故事）；死亡后损失灵魂并在死亡地点拾回的机制；多人联机的异步交互（留言、血迹、入侵）；对《仁王》《匹诺曹的谎言》《堕落之主》等后世作品产生深远影响；2024年《艾尔登法环》将FromSoftware推向新高度。
