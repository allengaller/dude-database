# Battlefield 1942（战地1942）

| 项目 | 数据 |
|------|------|
| **开发商** | DICE |
| **发行商** | Electronic Arts (EA) |
| **首发日期** | 2002年9月10日 |
| **平台** | PC / Mac OS |
| **类型** | 第一人称射击（FPS） / 大规模多人对战 |
| **销量** | 约300万份 |

## 简介

二战背景，64人多人对战，同盟国 vs 轴心国，太平洋、欧洲、北非战场。

## 关键设计

- 大规模多人对战
- 可驾驶载具（坦克、飞机、战舰）
- 兵种系统（侦察兵、突击兵、反坦克兵、医疗兵、工程师）
- 征服模式（Conquest）

## 行业影响

- 大规模载具FPS的开创者
- Mod支持（Desert Combat等经典Mod）
- 被PC Gamer评为史上最具影响力的PC游戏之一
