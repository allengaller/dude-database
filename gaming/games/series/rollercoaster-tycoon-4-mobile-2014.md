# RollerCoaster Tycoon 4 Mobile（过山车大亨4 移动版）

| 项目 | 数据 |
|------|------|
| **开发商** | On5 Apps / Pipeworks Software |
| **发行商** | Atari |
| **首发日期** | 2014年4月10日 |
| **平台** | iOS / Android |
| **类型** | Free-to-Play移动游戏 / 模拟经营 |

## 简介

移动平台的简化RCT，采用卡通车风格，包含内购系统（等待时间、货币购买）。

## 关键设计

- 卡通车风格美术设计
- 内购系统（等待时间、货币购买）
- 针对移动设备的简化操作

## 行业影响

- **系列评价最低的作品**
- Free-to-Play模式严重破坏游戏体验
- 粉丝强烈批评Atari的商业化方向
- 被称为"系列的耻辱"
