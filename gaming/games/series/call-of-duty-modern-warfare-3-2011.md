# Call of Duty: Modern Warfare 3（使命召唤：现代战争3）

| 项目 | 数据 |
|------|------|
| **开发商** | Infinity Ward / Sledgehammer Games / Raven Software |
| **发行商** | Activision |
| **首发日期** | 2011年11月8日 |
| **平台** | PC / PlayStation 3 / Xbox 360 / Wii / Nintendo DS / Mac OS |
| **类型** | 第一人称射击（FPS） |
| **销量** | 超2650万份 |

## 简介

现代战争三部曲终章；普莱斯和尤里（Yuri）追捕马卡洛夫（Makarov）；全球战争从纽约到汉堡到巴黎到迪拜。

## 关键设计

- Strike Package系统（Assault/Support/Specialist）
- 武器 Proficiency
- Spec Ops Survival模式
- 精英服务（Call of Duty Elite）

## 行业影响

发售16天收入超10亿美元；Infinity Ward创始人在开发期间被Activision解雇的法律纠纷（West/Zampella诉Activision案）；现代战争三部曲的完结；多人模式地图设计被广泛认为达系列高峰。
