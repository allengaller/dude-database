# Battlefield 2142（战地2142）

| 项目 | 数据 |
|------|------|
| **开发商** | DICE |
| **发行商** | Electronic Arts (EA) |
| **首发日期** | 2006年10月17日 |
| **平台** | PC / Mac OS |
| **类型** | 第一人称射击（FPS） / 大规模多人对战 |
| **销量** | 约100万份 |

## 简介

2142年冰河期未来战争，欧盟联军 vs 泛亚联军，泰坦模式（Titan Mode）。

## 关键设计

- 泰坦模式（攻击对方飞空母舰并摧毁核心）
- 机甲walker、悬浮坦克等未来载具

## 行业影响

- 泰坦模式被公认为系列最具创意的多人模式之一
- 对《泰坦陨落》等后世作品产生间接影响
