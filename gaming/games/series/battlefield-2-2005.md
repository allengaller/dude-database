# Battlefield 2（战地2）

| 项目 | 数据 |
|------|------|
| **开发商** | DICE |
| **发行商** | Electronic Arts (EA) |
| **首发日期** | 2005年6月21日 |
| **平台** | PC |
| **类型** | 第一人称射击（FPS） / 大规模多人对战 |
| **销量** | 约300万份 |

## 简介

现代战争背景，美军、解放军、中东联军三大阵营，32v32大规模对战。

## 关键设计

- 指挥官模式（Commander Mode）
- 小队系统（Squad System）
- 现代武器和载具
- 军衔和勋章解锁系统

## 行业影响

- 战地系列的真正成熟之作
- 现代战争题材的转向
- 指挥官和小队系统成为系列标志
- Project Reality Mod后来发展为独立游戏《战术小队》
