# Call of Duty: Warzone（使命召唤：战区）

| 项目 | 数据 |
|------|------|
| **开发商** | Infinity Ward / Raven Software |
| **发行商** | Activision |
| **首发日期** | 2020年3月10日 |
| **平台** | PC / PlayStation 4 / Xbox One / PlayStation 5 / Xbox Series X\|S |
| **类型** | 大逃杀（Battle Royale） / Free-to-Play |
| **玩家数** | 超1.1亿（2021年峰值） |

## 简介

150人（后扩展至200人）大逃杀；Verdansk地图（基于现代战争地图拼接）；Gulag复活机制；Loadout空投系统；Plunder模式。

## 关键设计

- Gulag（1v1复活赛）
- Buy Station购买系统
- Loadout空投（使用自定义武器配置）
- Gas圈（类似其他大逃杀的毒圈）

## 行业影响

**免费大逃杀改变CoD商业模式**。将CoD从年度60美元销售转向Free-to-Play+战斗通行证；2020年疫情期间的全球现象；反作弊Ricochet系统的引入；2021年太平洋更新、2022年Caldera更新、2023年Warzone 2.0/Al Mazrah；累计收入超数十亿美元。
