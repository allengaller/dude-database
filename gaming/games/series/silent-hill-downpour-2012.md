# Silent Hill: Downpour（寂静岭：暴雨）

| 项目 | 数据 |
|------|------|
| **开发商** | Vatra Games |
| **发行商** | Konami |
| **首发日期** | 2012年3月13日（北美）；2012年3月30日（欧洲） |
| **平台** | PlayStation 3 / Xbox 360 |
| **导演** | Marek Berka |
| **类型** | 心理恐怖（Psychological Horror）/ 生存恐怖（Survival Horror） |
| **销量** | PS3/X360版约30万份 |

## 简介

囚犯墨菲·彭德尔顿（Murphy Pendleton）在押运途中囚车事故后被困寂静岭，面对自己杀害虐待儿童犯 Patrick Napier 的过去，以及与狱警安妮·坎宁安（Anne Cunningham）的恩怨。

## 关键设计

- 开放世界探索（支线任务）
- 雨天时怪物更活跃
- 武器耐久系统
- 道德选择系统（影响结局）
- 回归心理恐怖而非动作化

## 行业影响

- Vatra Games（捷克工作室）的首部作品
- 开放世界尝试受到好评但技术表现不佳（帧率问题）
- 回归心理恐怖的叙事方向受到核心粉丝欢迎
- 但销量低迷导致系列再次沉寂
