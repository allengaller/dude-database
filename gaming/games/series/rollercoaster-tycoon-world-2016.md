# RollerCoaster Tycoon World（过山车大亨世界）

| 项目 | 数据 |
|------|------|
| **开发商** | Nvizzio Creations / Area 52 Games / Pipeworks Software |
| **发行商** | Atari |
| **首发日期** | 2016年11月15日 |
| **平台** | PC (Windows) |
| **类型** | 模拟经营 / 主题公园管理 / 建造 |
| **销量** | 约10万份 |

## 简介

3D主题公园建造游戏，支持Steam Workshop和多人合作模式。

## 关键设计

- **网格自由建造（Grid-free building）**：摆脱网格限制的自由建造系统
- **3D轨道编辑器**：全3D过山车轨道编辑
- **多人合作公园建设**：支持多名玩家共同建设主题公园
- Steam Workshop支持

## 行业影响

- **与《过山车之星》的直接竞争失败**
- 发售后与Frontier Developments的《过山车之星》（同年11月17日发售）形成直接对比
- 技术问题、性能问题和UI设计受到严厉批评
- 被粉丝和评论家一致认为远不如《过山车之星》
- Atari的品牌信誉进一步受损
