# Battlefield 3（战地3）

| 项目 | 数据 |
|------|------|
| **开发商** | DICE |
| **发行商** | Electronic Arts (EA) |
| **首发日期** | 2011年10月25日 |
| **平台** | PC / PS3 / Xbox 360 |
| **类型** | 第一人称射击（FPS） / 大规模多人对战 |
| **销量** | 超1500万份 |

## 简介

2014年近未来战争，美国海军陆战队亨利布莱克本上士战役，64人对战。

## 关键设计

- 寒霜引擎2（Frostbite 2）
- 极致画面表现
- Battlelog社交系统
- 载具和步兵平衡

## 行业影响

- EA与Activision全面竞争的标志
- 发售首周收入超5亿美元
- Operation Metro等地图成为经典
