# Ninja Gaiden（忍者龙剑传）

- **中文名**：忍者龙剑传
- **开发商**：Tecmo
- **发行商**：Tecmo
- **首发平台**：街机 / NES
- **首发日期**：1988年（街机）；1988年12月（NES北美）
- **游戏类型**：平台动作
- **行业影响**：NES版以电影化过场动画（Cinematic Cutscenes）著称，是家用机游戏叙事先驱；高难度设计理念成为"Tecmo难度"的代表；流畅的攀爬和攻击动画树立了2D动作游戏的新标准。
