# Final Fantasy（最终幻想）

- **中文名**：最终幻想
- **开发商**：Square
- **发行商**：Square / Nintendo
- **首发平台**：Family Computer / NES
- **首发日期**：1987年12月18日（日本）；1990年7月12日（北美）
- **游戏类型**：角色扮演（JRPG）
- **历史销量**：FC/NES版约199万份（数据来源：Square Enix官方销售数据）
- **游戏简介**：四名光之战士收集四颗元素水晶，击败黑暗势力并恢复世界平衡。
- **行业影响**：**日本RPG全球化的起点**。挽救了濒临破产的Square公司；引入了职业系统和ATB（Active Time Battle）时间轴战斗的前身；开启了持续至今的《最终幻想》传奇系列；对JRPG的叙事、美术和音乐标准产生深远影响。
