# Super Mario Bros.（超级马里奥兄弟）

- **中文名**：超级马里奥兄弟
- **开发商**：Nintendo R&D4
- **发行商**：Nintendo
- **首发平台**：Family Computer / Nintendo Entertainment System (NES)
- **首发日期**：1985年9月13日（日本）；1985年10月18日（北美）
- **游戏类型**：平台跳跃（Platformer）
- **Metacritic评分**：N/A
- **历史销量**：FC/NES版约4024万份（数据来源：任天堂官方销售数据，截至2024年3月）
- **游戏简介**：玩家控制马里奥穿越蘑菇王国的8个世界共32个关卡，最终从库巴（Bowser）手中救出碧奇公主（Princess Peach）。
- **行业影响**：**游戏史上最伟大的作品之一**。拯救了1983年"雅达利冲击"后濒临崩溃的北美游戏产业；定义了横版平台跳跃游戏的黄金标准；引入平滑滚动（Smooth Scrolling）和精确的平台物理；Time杂志将其列入"史上最伟大的50款电子游戏"；被大量学术研究作为游戏设计教科书。
