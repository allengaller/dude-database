# Tetris (Game Boy)（俄罗斯方块 Game Boy版）

- **开发商**：Nintendo R&D1 / Bullet-Proof Software
- **发行商**：Nintendo
- **首发平台**：Game Boy
- **首发日期**：1989年6月14日（日本）；1989年7月31日（北美）
- **游戏类型**：益智
- **历史销量**：Game Boy版约3500万份（数据来源：任天堂官方销售数据）
- **行业影响**：**Game Boy掌机成功的决定性因素**；与Game Boy硬件捆绑销售；确立了"便携益智游戏"的市场需求；俄罗斯方块与掌机的结合是游戏史上最成功的硬件-软件配对之一。
