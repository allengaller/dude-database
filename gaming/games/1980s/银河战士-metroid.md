# Metroid（银河战士）

- **中文名**：银河战士
- **开发商**：Nintendo R&D1 / Intelligent Systems
- **发行商**：Nintendo
- **首发平台**：Family Computer Disk System / NES
- **首发日期**：1986年8月6日（日本FDS）；1987年8月（北美NES）
- **游戏类型**：动作 / 平台 / 探索（"Metroidvania"类型鼻祖）
- **历史销量**：NES版约273万份（数据来源：任天堂官方销售数据）
- **行业影响**：创造了"Metroidvania"这一游戏子类型（与《恶魔城》共同命名）；首次以女性角色（Samus Aran）作为可操控主角（通关彩蛋揭示）；引入非线性地图探索和"能力锁"（Ability Gating）设计；横版动作与科幻恐怖氛围的完美结合。
