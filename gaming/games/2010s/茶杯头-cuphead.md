# Cuphead（茶杯头）

- **中文名**：茶杯头
- **开发商**：Studio MDHR
- **发行商**：Studio MDHR
- **首发平台**：Xbox One / PC
- **首发日期**：2017年9月29日
- **游戏类型**：跑动射击 / Boss Rush
- **Metacritic评分**：88/100 (PC) / 86/100 (XONE)
- **历史销量**：约600万份（数据来源：Studio MDHR官方数据，截至2020年）
- **行业影响**：**手绘动画风格的技术奇迹**。Chad和Jared Moldenhauer兄弟的愿景；1930年代橡皮管动画（Rubber Hose Animation）风格的手绘每一帧；爵士乐原声（Kristofer Maddigan作曲）；极高的Boss战难度；2017年TGA最佳独立游戏和最佳首秀独立游戏；2022年《The Delicious Last Course》DLC发售；2022年Netflix动画剧集改编。
