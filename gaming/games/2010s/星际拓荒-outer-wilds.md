# Outer Wilds（星际拓荒）

- **中文名**：星际拓荒
- **开发商**：Mobius Digital
- **发行商**：Annapurna Interactive
- **首发平台**：Xbox One / PC
- **首发日期**：2019年5月28日（Xbox One/EGS）；2019年6月18日（Steam）
- **游戏类型**：冒险 / 探索 / 解谜
- **Metacritic评分**：85/100 (XONE) / 85/100 (PC)
- **行业影响**：**探索驱动游戏的杰作**。22分钟时间循环的宇宙；手风琴配乐（Andrew Prahlow作曲）的叙事作用；无战斗、无升级、纯探索的设计理念；Nomai文明的考古式解谜；2019年TGA最佳独立游戏；2020年DLC《Echoes of the Eye》扩展内容；被大量玩家和媒体誉为"最完美的游戏设计"。
