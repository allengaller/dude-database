# Dota 2（刀塔2）

- **中文名**：刀塔2
- **开发商**：Valve Corporation
- **发行商**：Valve Corporation
- **首发平台**：PC / Linux / Mac OS
- **首发日期**：2013年7月9日（正式版）
- **游戏类型**：MOBA / 动作RTS
- **Metacritic评分**：90/100 (PC)
- **行业影响**：**电竞产业的基石**。起源于《魔兽争霸3》自定义地图Dota；Valve收购并商业化的Free-to-Play模式；The International（TI）电竞赛事（2011年起，TI10奖金池超4000万美元，数据来源：Valve官方数据）；Source 2引擎升级；Steam Workshop的Mod生态；对《英雄联盟》《王者荣耀》等后世MOBA产生竞争和推动。
