# Inside（深入）

- **中文名**：深入
- **开发商**：Playdead
- **发行商**：Playdead
- **首发平台**：Xbox One / PC
- **首发日期**：2016年6月29日
- **游戏类型**：解谜 / 平台 / 恐怖
- **Metacritic评分**：87/100 (XONE) / 87/100 (PC)
- **行业影响**：《Limbo》的精神续作。无对白的极简叙事；2.5D横版解谜的极致运用；水的物理模拟和恐怖氛围；结局的惊人反转；2016年TGA最佳艺术指导和最佳独立游戏；对《Little Nightmares》等后世作品产生影响。
