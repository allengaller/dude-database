# Yakuza 0（如龙0：誓约的场所）

- **中文名**：如龙0：誓约的场所
- **开发商**：Ryu Ga Gotoku Studio
- **发行商**：Sega
- **首发平台**：PlayStation 3 / PlayStation 4 / PC
- **首发日期**：2015年3月12日（日本）/ 2017年1月24日（欧美）
- **游戏类型**：动作冒险 / 开放世界
- **Metacritic评分**：85/100 (PS4)
- **历史销量**：超250万份（数据来源：Sega官方数据）
- **行业影响**：**如龙系列最佳入门之作**。双主角结构（桐生一马/真岛吾朗）展现1988年神室町的黄金时代；主线剧情严肃黑帮叙事与荒诞支线内容的完美融合成为系列标志；战斗风格切换系统（三种格斗风格）；不动产经营和娱乐场所等丰富小游戏；作为前传降低了系列入门门槛；西方市场发售后口碑爆发，推动系列全球化；证明了日式开放世界在3A领域的独特价值。
