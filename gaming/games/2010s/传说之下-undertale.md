# Undertale（传说之下）

- **中文名**：传说之下
- **开发商**：Toby Fox
- **发行商**：Toby Fox
- **首发平台**：PC / Mac / Linux
- **首发日期**：2015年9月15日
- **游戏类型**：角色扮演 / 独立
- **Metacritic评分**：92/100 (PC)
- **历史销量**：约1000万份（数据来源：Toby Fox公开数据，截至2023年）
- **游戏简介**：人类小孩落入地下怪物世界，可选择杀戮或饶恕每一个敌人，走向不同结局。
- **行业影响**：**独立游戏的文化现象**。Toby Fox一人开发；Meta-narrative打破第四面墙的设计；可完全和平通关的理念；Megalovania等原声音乐成为网络迷因（meme）；对《Deltarune》等后世作品产生影响；2019年 Nintendo Switch 移植版发售。
