# Journey（风之旅人）

- **中文名**：风之旅人
- **开发商**：Thatgamecompany
- **发行商**：Sony Computer Entertainment
- **首发平台**：PlayStation 3
- **首发日期**：2012年3月13日
- **游戏类型**：冒险 / 艺术游戏
- **Metacritic评分**：92/100 (PS3)
- **历史销量**：约700万份（数据来源：Thatgamecompany官方数据，截至2020年）
- **游戏简介**：玩家在沙漠中扮演无名旅人，向远方的山峰前进，途中可与匿名玩家结伴同行。
- **行业影响**：**艺术游戏的里程碑**。陈星汉（Jenova Chen）的杰作；无语言的纯视觉和音乐叙事；匿名多人联机的情感连接（无法文字交流，只能发出鸣叫）；Austin Wintory的配乐获格莱美奖提名（史上首个获此殊荣的游戏音乐）；证明了短流程（约2小时）艺术游戏可获得商业成功；对《Abzû》《Gris》等后世艺术游戏产生影响。
