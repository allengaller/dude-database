# Doom（毁灭战士 / DOOM 2016）

- **中文名**：毁灭战士（2016）
- **开发商**：id Software
- **发行商**：Bethesda Softworks
- **首发平台**：PC / PlayStation 4 / Xbox One
- **首发日期**：2016年5月13日
- **游戏类型**：第一人称射击（FPS）
- **Metacritic评分**：85/100 (PC) / 85/100 (PS4) / 87/100 (XONE)
- **历史销量**：约300万份（数据来源：SuperData估算，发售首月）
- **行业影响**：**FPS经典的现代重生**。id Tech 6引擎的技术展示；"Push Forward Combat"设计理念（鼓励近战 Glory Kill 获取资源）；Mick Gordon的重金属工业配乐；快节奏移动和垂直空间利用；2016年重启系列的成功为2020年《毁灭战士：永恒》和2025年《毁灭战士：黑暗时代》铺平道路。
