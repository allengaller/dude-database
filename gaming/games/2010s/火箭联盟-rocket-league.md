# Rocket League（火箭联盟）

- **中文名**：火箭联盟
- **开发商**：Psyonix
- **发行商**：Psyonix / Epic Games（2019年后）
- **首发平台**：PC / PlayStation 4
- **首发日期**：2015年7月7日
- **游戏类型**：体育 / 载具足球
- **Metacritic评分**：85/100 (PC) / 85/100 (PS4)
- **历史销量**：全平台累计超7500万玩家（数据来源：Psyonix官方数据，2020年）
- **行业影响**：**电子竞技的新兴力量**。火箭动力汽车踢足球的简单概念；物理引擎驱动的技巧性操作；Free-to-Play（2020年转型）的成功案例；2017年RLCS（Rocket League Championship Series）电竞联赛；2019年Epic Games收购Psyonix；跨平台联机的早期推动者。
