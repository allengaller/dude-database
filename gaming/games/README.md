# 游戏数据库

**总游戏**: 383 款活跃 + 73 款已归档
**数据截止**: 2026-07-15

本数据库收录电子游戏产业历史上具有里程碑意义的经典作品和重点系列。每个游戏独立一个 `.md` 文件, 文件命名采用 **中文名-英文原名** 格式 (如 `艾尔登法环-elden-ring.md`)。

---

## 目录结构

```
gaming/games/
├── 1980s/    1980年代经典
├── 1990s/    1990年代经典
├── 2000s/    2000年代经典
├── 2010s/    2010年代经典
├── 2020s/    2020年代经典
├── 2021/     2021年
├── 2022/     2022年
├── 2023/     2023年
├── 2024/     2024年
├── 2025/     2025年
├── series/   重点系列核心作品 (生化危机/使命召唤/战地/寂静岭/过山车大亨/最终幻想/塞尔达/宝可梦)
└── _superseded/  已归档的重复版本 (73 个, 不再维护)
```
