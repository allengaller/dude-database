## 背景故事

2033年，在被真菌感染毁灭的世界中，幸存的人类在隔离区中苟延残喘。乔尔（Joel），一个失去女儿的冷漠走私者，被迫护送一个14岁的女孩艾莉（Ellie）——她对感染免疫，可能是研制疫苗的关键——穿过整个美国。两人从波士顿隔离区出发，穿越被遗弃的城市、森林和山区，一路上经历了其他幸存者派系、感染者和其他威胁。旅途中，两人建立了如同父女般的纽带。最终，乔尔做出了一个将影响整个世界命运的选择。

## 游戏特色

### 情感叙事

The Last of Us达到了游戏叙事的新高度：

- **角色驱动**：乔尔和艾莉的关系是游戏的核心
- **无选择的叙事**：不同于大多数RPG，本作没有道德选择系统
- **信任建立**：艾莉的AI伙伴系统增加了真实感

### 游戏机制

| 机制 | 说明 |
|------|------|
| 潜行和战斗 | 利用环境和敌人AI进行潜行或战斗 |
| 资源稀缺 | 弹药和物资极其有限 |
| 聆听模式 | 利用声音确定敌人位置 |
| 艾莉协助 | 艾莉在关键时刻提供帮助 |

### 感染者类型

| 类型 | 特点 |
|------|------|
| 普通感染者 | 被感染的人类，会主动攻击 |
| 跑者 | 感染早期，行动敏捷 |
| 潜伏者 | 失明但听觉敏锐 |
| 巨无霸 | 巨型变异体，有护甲保护 |

### 业界地位

- 获得超过200项年度最佳游戏奖项
- 被认为是游戏作为叙事媒体的巅峰之作
- PS3上最畅销的游戏之一
