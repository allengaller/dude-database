## 背景故事

1964年，代号“斯内克”（Snake）的年轻士兵被派往苏联执行一项特殊任务：营救被扣押的科学家谢尔盖·索科洛夫（Sergei Gurlukovich）将军，并阻止正在研发中的超级武器"Shagohod"。随着任务深入，斯内克发现他的导师"Major Zero"和战友"Ocelot"都有隐藏的议程，并最终发现这一切与一个被称为"第509支部"的秘密计划有关。

## 游戏特色

### 丛林环境

- **伪装系统**：根据环境选择迷彩
- **生存要素**：饮食、治疗、捕捉动物
- **第一人称潜入**：继承了MGS2的第一人称模式

### 游戏系统

| 系统 | 说明 |
|------|------|
| CQC | 近身格斗技术，可以捆绑敌人 |
| 伪装迷彩 | 根据环境调整服装 |
| 生存观察 | 治疗伤口、捕捉食物 |
| 植物采集 | 利用野外植物恢复体力 |

### 系列地位

MGS3是《潜龙谍影》系列的前传，奠定了整个系列的基础：
- 解释了Big Boss的起源
- 引入了Shagohod等经典元素
