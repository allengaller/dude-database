## 背景故事

Wii Sports是Wii主机的首发护航作品，包含网球、棒球、乒乓球、保龄球、高尔夫五种运动游戏。玩家通过Wii遥控器的体感操作来进行游戏。

## 游戏特色

### 体感操作

| 运动 | 操作 |
|------|------|
| 网球 | 挥动遥控器击球 |
| 棒球 | 挥动遥控器击球 |
| 乒乓球 | 挥动遥控器击球 |
| 保龄球 | 滚动遥控器投球 |
| 高尔夫 | 挥动遥控器击球 |

### 成功影响

- Wii主机最佳销售游戏
- 全球销量超过8000万份
- 将体感游戏带入主流
