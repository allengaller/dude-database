## 背景故事

利基亚同盟（Lycia）的诸侯之子罗伊（Roy）在父亲病倒后，被迫率领军队抵抗伯尔尼王国（Bern）的侵略。随着战争推进，罗伊发现伯尔尼国王泽菲鲁斯（Zephiel）的野心背后，是远古时代被封印的魔龙伊冬（Idunn）的复活阴谋。罗伊必须收集八把神将器，最终封印魔龙，拯救大陆。

## 游戏特色

### 系列首款掌机作品

《封印之剑》是火焰纹章系列首次登陆掌机平台：

- **GBA便携性**：随时随地游玩的SRPG体验
- **精简地图**：适配掌机屏幕的紧凑战术地图
- **快速节奏**：战斗动画可跳过，适合碎片时间
- **通信对战**：GBA通信线支持对战

### 核心系统

| 系统 | 说明 |
|------|------|
| 永久死亡 | 角色阵亡后不可复活（系列传统） |
| 武器三角 | 剑克斧、斧克枪、枪克剑 |
| 支援对话 | 角色间的羁绊系统，提升战斗数值 |
| 转职系统 | 达到条件后职业升级 |
| 多结局 | 根据条件触发不同结局 |

### 罗伊（Roy）

本作主角，利基亚同盟的年轻领主。后作为可操作角色登场于《任天堂明星大乱斗DX》，成为西方玩家认识火焰纹章系列的契机。

## 关键里程碑

- 火焰纹章系列首款掌机作品，开创了便携式SRPG的先河
- 罗伊通过《大乱斗DX》首次向西方玩家展示了火焰纹章系列
- 为后续《烈火之剑》（西方系列首作）的海外发行铺平道路
- 证明了SRPG在掌机平台的商业可行性
- 仅在日本发行，成为系列最知名的"未出海"作品之一
