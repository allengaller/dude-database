## 背景故事

在桃花公主城堡的星空派对上，突然出现了一个威胁——库巴（ Bowser）率领他的军队攻占了城堡，并利用巨型战机将城堡炸飞。桃花公主和奥德师被迫乘坐流星逃亡，城堡的残骸散落在各个星系中。路易吉（ Luigi）收到了神秘“信使”的消息，踏上了收集“力量之星的旅程。在多个星系中，马里奥必须从库巴手中拯救桃子公主，并在这个过程中发现这一切背后的更大威胁——“黑暗星星”的核心。

## 游戏特色

### 重力星球系统

Super Mario Galaxy开创性地引入了基于星球的重力系统：
- **小型星球**：每个星球都有独立的小型重力场
- **球体表面行走**：玩家可以在星球表面行走，绕到“背面”
- **星系探索**：每个星系包含多个小星球，各有独特重力特性

### 游戏世界

| 世界 | 特点 |
|跨# | - |
| 托里尼星云 | 起始星系，有基本教程 |
| 灭亡火山 | 火山主题的熔岩星球 |
| 比安卡星云 | 冰雪世界的星球 |
| 幽灵星系 | 幽灵主题的恐怖星球 |
| 海洋星系 | 水下星球 |
| 库巴的黑暗星系 | 最终世界 |

### 创新操控

- **Wii遥控器体感**：利用遥控器的指向功能收集星尘和瞄准
- **双人合作**：二号玩家可以扮演路易吉或桃子辅助
- **旋转攻击**：利用旋转攻击破解特定敌人

### 业界地位

Super Mario Galaxy获得了业界的一致好评：
- 首个获得Fami通满分的Wii游戏
- GameSpot年度游戏
- 多项年度最佳游戏奖项
