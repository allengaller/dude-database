## 背景故事

在《暗黑破坏神》的故事结束后，黑暗流浪者（ Dark Wanderer）——曾经是正派英雄，现在是迪亚波罗的容器——踏上了前往东方寻找世界之石的旅程。玩家扮演的英雄必须追捕黑暗流浪者，阻止迪亚波罗复活。在旅程中，玩家将穿越罗达蒙特沙漠、库拉斯特海港、神秘的水晶深处，最终到达迪亚波罗复活之地。

## 游戏特色

### ARPG类型定义

Diablo II 定义了暗黑破坏神like（即 ARPG）的类型标准：

- **即时动作战斗**：实时攻击，不需要暂停
- **随机生成**：怪物、物品和地图的随机性
- **物品驱动**：复杂的物品和装备系统
- **天赋树**：角色Build的多样性

### 角色职业

| 职业 | 特点 |
|------|------|
| 亚马逊 | 远程攻击，弓箭和长矛 |
| 野蛮人 | 近战武器，双手武器 |
| 死灵法师 | 召唤和毒系魔法 |
| 游侠 | 元素弓和陷阱 |
| 女巫 | 元素魔法 |
| 刺客 | 武术和陷阱 |

### 资料片：Lord of Destruction

2001年发布的资料片增加了两个新职业：
- 德鲁伊（Druid）：变形和元素魔法
- 刺客（Assassin）：武术和影子技能
