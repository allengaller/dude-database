## 背景故事

科尔沃·阿塔诺（Corvo Attano），曾经是女皇最信任的皇家保护者，如今被诬陷为刺杀女皇的凶手。在被囚禁并遭受酷刑后，他被神秘组织“布萊克斯威夫特”（The Loyalist）营救。带着一套可以操控时间、空间和生物的超自然力量，以及各种高科技装备，科尔沃必须在严格控制的城市中追杀真凶，拯救女皇的女儿，并最终决定这个腐败帝国的命运。

## 游戏特色

### 潜行游戏设计

Dishonored 被认为是潜行游戏的最高成就之一：
- **多重路径**：每个关卡都有多种通过方式
- **高选择性**：玩家可以选择杀或不杀、暴露或潜行
- **后果系统**：杀人数影响结局和世界状态

### 超自然能力

| 能力 | 说明 |
|------|------|
| 时间停止 | 减慢时间流动 |
| 瞬移 | 短距离传送 |
| 占据 | 占据敌人身体 |
| 组合 | 能力可以叠加使用 |

### 业界影响

- 获得了超过150项年度最佳游戏奖项
- 被认为是潜行游戏类型的文艺复兴
- 影响了《耻辱2》和《死亡循环》等续作
