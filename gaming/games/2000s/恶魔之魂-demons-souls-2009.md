## 背景故事

北方王国Boletaria被古老的恶魔唤醒，浓雾笼罩大地，吞噬一切生灵。无名战士踏入雾中，必须击败各区域的Boss恶魔，收集恶魔之魂，最终决定世界的命运——是封印Old One还是成为新的恶魔。

## 游戏特色

### 核心设计

| 系统 | 说明 |
|------|------|
| 难度即设计 | 高难度作为核心体验，死亡是学习过程 |
| 灵魂系统 | 死亡掉落灵魂，一次机会回收 |
| 世界倾向 | 黑白倾向影响难度和隐藏内容 |
| 角色构建 | 无职业限制，自由分配属性 |

### 异步多人

- **留言系统**：玩家在地上留下提示或陷阱警告
- **血迹系统**：看到其他玩家的死亡回放
- **幻影入侵**：其他玩家以黑/白幻影形式出现
- **合作与PvP**：召唤或被入侵

### 业界影响

- 魂类游戏（Souls-like）的诞生原点
- 宫崎英高（Hidetaka Miyazaki）的导演处女作
- "难度即设计"理念颠覆了当时游戏越做越简单的趋势
- 异步多人系统（留言/血迹/幻影）开创性设计
- 直接催生Dark Souls系列、Bloodborne、Sekiro、Elden Ring等作品谱系
- 2020年Bluepoint Games制作PS5重制版
