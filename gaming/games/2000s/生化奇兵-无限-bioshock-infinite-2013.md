## 背景故事

1912年，饱受噩梦困扰的前Pinkerton侦探布克·德威特（Booker DeWitt）被派往悬浮在天空的城市“哥伦比亚”——一个由美国政府秘密建造的飞行乌托邦。在那里，他必须找到并解救一名名为“安娜·德威特”的女子。然而，随着他对这座城市的深入了解，发现这个所谓的“理想国”实际上是一个充满狂热宗教徒和阴谋的地方。更令人震惊的是，他发现这个女孩与自己的过去有着无法分割的联系。

## 游戏特色

### 天城哥伦比亚

作为前作海底城市“极乐城”的对立面，哥伦比亚是一个漂浮在天空的城市：
- **空中城市**：完全在天空中的浮岛
- **宗教狂热**：将美国建国神话宗教化的邪教
- **悬浮轨道**：利用悬浮铁路系统快速移动

### 游戏系统

| 系统 | 说明 |
|------|------|
| 天城之泪 | 用于购买升级和回复 |
| 武器 | 两把武器同时装备 |
|  Vigors | 特殊能力，如“恶魔之缚” |
| 天城钩锁 | 用于在轨道间快速移动 |

### 剧情深度

BioShock Infinite的叙事延续并超越了前作的主题：
- **美国例外论的批判**：对“山巅之城”美国梦的反思
- **时间旅行**：涉及多重现实和身份认同
- **随机应变与命运的讨论**
