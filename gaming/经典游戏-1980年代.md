# 1980年代经典游戏数据库（数据截止：2026年4月）

**数据说明**：本数据库收录1980年代（1980-1989）发行的具有行业里程碑意义的电子游戏作品，按游戏行业专业标准整理。

---

## 行业概述

1980年代是电子游戏产业的形成期。街机（Arcade）市场在此期间达到第一个高峰，家用游戏机市场由Atari 2600开启，任天堂Family Computer（红白机）于1983年推出后重新定义了家用游戏标准。本年代诞生了平台游戏、动作冒险、角色扮演等多种游戏类型的雏形。

**数据来源**：基于Newzoo游戏行业历史报告、任天堂/世嘉官方档案、IGN/Screen Digest历史统计整理

## 1980年

### Pac-Man（吃豆人）
- **中文名**：吃豆人
- **开发商**：Namco（南梦宫）
- **发行商**：Namco / Midway（北美）
- **首发平台**：街机（Arcade）
- **首发日期**：1980年5月22日（日本）
- **游戏类型**：迷宫追逐（Maze / Chase）
- **Metacritic评分**：N/A（发行年代早于评分体系）
- **历史销量**：街机版全球收入约35亿美元（1980年代累计，数据来源：Twin Galaxies/世嘉Sammy Holdings历史档案）
- **游戏简介**：玩家控制黄色圆形角色Pac-Man在迷宫中吃掉所有豆子，同时躲避四色幽灵。吃大力丸后可短暂反追幽灵。
- **行业影响**：游戏史上第一个拥有完整角色形象IP的游戏；确立了迷宫追逐类游戏范式；衍生出动画、音乐、 merchandise等跨媒体产业链；全球认知度最高的游戏角色之一。

## 1981年

- **发行商**：Nintendo

## 1984年

### Tetris（俄罗斯方块）
- **中文名**：俄罗斯方块
- **开发商**：Alexey Pajitnov（阿列克谢·帕基特诺夫）
- **发行商**：Soviet Academy of Sciences / 多平台授权
- **首发平台**：Electronika 60（苏联家用电脑）
- **首发日期**：1984年6月6日
- **游戏类型**：益智 / 消除（Puzzle）
- **历史销量**：全平台累计销量超5亿份（含免费移动端，数据来源：The Tetris Company 2024年官方统计）
- **游戏简介**：玩家控制七种不同形状的方块（Tetromino）下落并拼接，填满整行即可消除，避免方块堆叠至顶部。
- **行业影响**：**人类历史上销量最高的游戏系列之一**；从苏联走向全球的跨文化现象；定义了"下落式益智"游戏类型；被大量学术研究用于认知科学和空间推理测试；Game Boy版（1989年）成为任天堂掌机战略的支柱产品。

### Elite（精英）
- **开发商**：David Braben, Ian Bell
- **发行商**：Acornsoft / Firebird
- **首发平台**：BBC Micro
- **首发日期**：1984年9月
- **游戏类型**：太空交易 / 开放世界模拟
- **行业影响**：**开放世界游戏的真正鼻祖**；使用 procedural generation（程序生成）技术创造无限星系；引入声望系统和派系机制；3D线框图形在家用机上的早期实现；对《无人深空》《星际公民》等后世作品影响深远。

### Knight Lore（骑士传说）
- **开发商**：Ultimate Play the Game（Rare前身）
- **发行商**：Ultimate Play the Game
- **首发平台**：ZX Spectrum
- **首发日期**：1984年11月
- **游戏类型**：动作冒险 / 等角投影（Isometric）
- **行业影响**：首创等角投影（Isometric）视角的动作冒险游戏；确立了Filmation引擎的技术标杆；直接影响了后世《暗黑破坏神》《博德之门》等游戏的视角设计。

- **开发商**：Nintendo R&D4
- **发行商**：Nintendo
- **首发平台**：Family Computer / Nintendo Entertainment System (NES)
- **首发日期**：1985年9月13日（日本）；1985年10月18日（北美）

- **首发日期**：1985年10月

## 1986年

- **开发商**：Nintendo R&D4
- **发行商**：Nintendo
- **首发平台**：Family Computer Disk System
- **首发日期**：1986年2月21日（日本）；1987年8月22日（北美NES）

- **发行商**：SEGA

- **首发日期**：1986年9月
- **游戏类型**：竞速 / 驾驶模拟
