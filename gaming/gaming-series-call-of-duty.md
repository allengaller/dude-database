使命召唤是全球最畅销、最具影响力的第一人称射击游戏系列，也是娱乐产业最成功的IP之一。自2007年《使命召唤4：现代战争》起，系列成为年度化发售的3A标杆，其多人模式定义了主机FPS的在线竞技标准。Warzone（2020年）的推出将系列扩展至大逃杀领域，进一步巩固了其市场统治地位。系列对全球电竞产业、直播文化和FPS游戏设计标准产生了深远影响。

## 编年史与核心作品

### 二战题材时期（2003-2008）

#### Call of Duty（使命召唤）
- **开发商**：Infinity Ward / Aspyr（Mac）
- **首发日期**：2003年10月29日
- **平台**：PC / Mac OS / N-Gage / PS3/X360（合集版）
- **销量**：约470万份
- **核心内容**：以二战欧洲战场为背景，玩家分别扮演美国101空降师、英国SAS和苏联红军的士兵，体验诺曼底登陆、市场花园行动和斯大林格勒保卫战。
- **关键设计**：多阵营叙事结构；电影化脚本事件（Scripted Events）；NPC队友系统；大幅改进的《荣誉勋章》式二战FPS体验
- **行业影响**：Infinity Ward的首部作品，由前《荣誉勋章》团队核心成员创立；确立了"电影化二战FPS"的标准

#### Call of Duty 2（使命召唤2）
- **开发商**：Infinity Ward / Aspyr（Mac）
- **首发日期**：2005年10月25日
- **平台**：PC / Xbox 360 / Mac OS
- **销量**：约588万份
- **核心内容**：Xbox 360首发护航大作；继续二战多战线叙事；引入再生血量（Regenerating Health）机制。
- **行业影响**：Xbox 360平台的技术展示；再生血量机制后来被系列长期采用；确立了Infinity Ward-Treyarch的交替开发模式

#### Call of Duty 3（使命召唤3）
- **开发商**：Treyarch / Pi Studios / Beenox
- **首发日期**：2006年11月7日
- **平台**：PlayStation 2 / PlayStation 3 / Xbox / Xbox 360 / Wii
- **销量**：约732万份
- **核心内容**：Treyarch首次主导开发的正传作品；诺曼底战役后的法国解放；载具战斗的增加。
- **行业影响**：Treyarch从辅助开发转向正传的转折点；证明了交替开发模式的可行性

### 现代战争时代（2007-2012）

#### Call of Duty 4: Modern Warfare（使命召唤4：现代战争）
- **开发商**：Infinity Ward
- **首发日期**：2007年11月5日
- **平台**：PC / PlayStation 3 / Xbox 360 / Mac OS / Wii / Nintendo DS
- **销量**：超2000万份（数据来源：Activision官方数据）
- **核心内容**：从二战转向现代战争；SAS队长约翰·普莱斯（John Price）和中士约翰·"肥皂"·麦克塔维什（John "Soap" MacTavish）追捕俄罗斯极端民族主义者伊姆兰·扎卡耶夫（Imran Zakhaev）；美军线（保罗·杰克逊中士）在中东的战争。
- **关键设计**：**现代武器和装备系统**；Perk系统（3个Perk槽）；经验值和等级解锁系统；Prestige模式；Killstreak奖励（3/5/7连杀）；Class自定义系统
- **行业影响**：**FPS游戏历史上最重要的转折点之一**。将FPS从二战推向现代军事题材；建立了主机FPS多人竞技的完整框架（等级、解锁、Perk、连杀）；2007年TGA最佳动作游戏、最佳多人游戏；被IGN、GameSpot等评为"史上最伟大的FPS之一"；直接催生了《战地：叛逆连队》《荣誉勋章2010》等竞争者

#### Call of Duty: World at War（使命召唤：战火世界）
- **开发商**：Treyarch
- **首发日期**：2008年11月11日
- **平台**：PC / PlayStation 3 / Xbox 360 / Wii / Nintendo DS / Mac OS
- **销量**：超1575万份
- **核心内容**：回归二战但聚焦太平洋战场（美国海军陆战队米勒）和东线（苏联红军雷泽诺夫）；引入丧尸模式（Nazi Zombies）。
- **关键设计**：丧尸模式（Nacht der Untoten）首次登场；火焰喷射器和坦克；合作战役模式
- **行业影响**：丧尸模式的诞生（后来成为系列标志性附加模式）；加里·奥德曼配音雷泽诺夫；Treyarch确立了自己的暗黑风格

#### Call of Duty: Modern Warfare 2（使命召唤：现代战争2）
- **开发商**：Infinity Ward
- **首发日期**：2009年11月10日
- **平台**：PC / PlayStation 3 / Xbox 360 / Mac OS
- **销量**：超2500万份（数据来源：Activision官方数据，截至2023年史上最畅销的CoD之一）
- **核心内容**："不准说俄语"（No Russian）关卡引发巨大争议；141特遣队（普莱斯、肥皂、幽灵、小强）追捕谢泼德将军（General Shepherd）的背叛；美军线（拉米雷斯、福利中士）保卫华盛顿特区。
- **关键设计**：Killstreak扩展（3/5/7/9/11/15/25）；AC130炮艇机可操作；特种任务模式（Spec Ops）；Commando Pro等争议性Perk；Dual Wield双持
- **行业影响**：发售首日收入超3.1亿美元（破娱乐产品首日纪录）；"No Russian"关卡引发全球媒体关于游戏暴力的讨论；幽灵（Ghost）的角色 viral；Special Ops模式成为合作标杆；2020年《现代战争2 战役重制版》发售

#### Call of Duty: Black Ops（使命召唤：黑色行动）
- **开发商**：Treyarch
- **首发日期**：2010年11月9日
- **平台**：PC / PlayStation 3 / Xbox 360 / Wii / Nintendo DS / Mac OS
- **销量**：超2620万份
- **核心内容**：冷战背景；亚历克斯·梅森（Alex Mason）被洗脑和数字密码的悬疑叙事；雷泽诺夫（Reznov）的回归；古巴、越南、香港、乌拉尔山脉等地的黑色行动。
- **关键设计**：COD Points货币系统；Wager Match赌博模式；Combat Training AI对战；丧尸模式扩展（Kino der Toten、Five、Dead Ops Arcade）；剧场模式（Theater Mode）
- **行业影响**：Treyarch的巅峰之作；冷战题材的FPS标杆；丧尸模式的全面进化（加入角色和故事线）；剧场模式革新了玩家内容创作；2010年TGA提名；多结局和数字密码的叙事深度

#### Call of Duty: Modern Warfare 3（使命召唤：现代战争3）
- **开发商**：Infinity Ward / Sledgehammer Games / Raven Software
- **首发日期**：2011年11月8日
- **平台**：PC / PlayStation 3 / Xbox 360 / Wii / Nintendo DS / Mac OS
- **销量**：超2650万份
- **核心内容**：现代战争三部曲终章；普莱斯和尤里（Yuri）追捕马卡洛夫（Makarov）；全球战争从纽约到汉堡到巴黎到迪拜。
- **关键设计**：Strike Package系统（Assault/Support/Specialist）；武器 Proficiency；Spec Ops Survival模式；精英服务（Call of Duty Elite）
- **行业影响**：发售16天收入超10亿美元（数据来源：Activision新闻稿）；Infinity Ward创始人在开发期间被Activision解雇的法律纠纷（West/Zampella诉Activision案）；现代战争三部曲的完结；多人模式地图设计被广泛认为达系列高峰

#### Call of Duty: Black Ops II（使命召唤：黑色行动2）
- **开发商**：Treyarch
- **首发日期**：2012年11月13日
- **平台**：PC / PlayStation 3 / Xbox 360 / Wii U
- **销量**：超2900万份（数据来源：Activision官方数据，截至2023年系列销量最高作品之一）
- **核心内容**：1980年代（梅森父子）和2025年（大卫·梅森）双线叙事；Strike Force任务的RTS元素；Raul Menendez的反美恐怖主义叙事。
- **关键设计**：**Pick 10 Create-a-Class系统**；Scorestreak替代Killstreak；联赛模式（League Play）；丧尸模式Transit和Grief；分支剧情选择
- **行业影响**：首个引入分支剧情和多重结局的CoD；Pick 10系统成为后续作品标配；2025年设定引入未来科技（无人机、动力装甲）；电子竞技的进一步制度化；丧尸模式的 Transit 大地图和移动Bank系统

### 次世代过渡期（2013-2016）

#### Call of Duty: Ghosts（使命召唤：幽灵）
- **开发商**：Infinity Ward / Raven Software / Neversoft / Treyarch
- **首发日期**：2013年11月5日
- **平台**：PC / PlayStation 3 / PlayStation 4 / Xbox 360 / Xbox One / Wii U
- **销量**：超1920万份
- **核心内容**：近未来设定（ODIN空间站武器）；Logan Walker和"幽灵"小队的叙事；狗伙伴Riley的加入。
- **关键设计**：Squad模式（AI队伍管理）；Extinction模式（外星虫族替代丧尸）；动态地图事件；Create-a-Soldier系统
- **行业影响**：PS4/Xbox One跨世代发售的首个CoD；Extinction模式实验性替代丧尸；评价相对平庸，被认为是系列的低谷期之一

#### Call of Duty: Advanced Warfare（使命召唤：高级战争）
- **开发商**：Sledgehammer Games / Raven Software / High Moon Studios
- **首发日期**：2014年11月4日
- **平台**：PC / PlayStation 3 / PlayStation 4 / Xbox 360 / Xbox One
- **销量**：超1780万份
- **核心内容**：2054年设定；Kevin Spacey饰演的Jonathan Irons和Atlas私人军事公司；Exo Suit动力外骨骼。
- **关键设计**：**Exo Suit双跳和侧移**；Supply Drop补给箱系统（随机开箱的开端）；Uplink游戏模式；Pick 13系统
- **行业影响**：Exo Suit大幅改变了多人游戏移动方式（垂直性增加）；Supply Drop系统引入随机开箱商业化模式（后来备受争议）；Kevin Spacey的表演成为卖点；但被部分粉丝批评"太科幻"

#### Call of Duty: Black Ops III（使命召唤：黑色行动3）
- **开发商**：Treyarch / Raven Software / Beenox
- **首发日期**：2015年11月6日
- **平台**：PC / PlayStation 3 / PlayStation 4 / Xbox 360 / Xbox One
- **销量**：超2650万份
- **核心内容**：2065年设定；DNI（Direct Neural Interface）神经直连；黑市（Black Market）系统；丧尸模式Shadows of Evil（Jeff Goldblum等明星配音）。
- **关键设计**： Specialists 专家角色（每个拥有独特技能和武器）；Gunsmith深度武器自定义；丧尸模式GobbleGum；Nightmares战役模式（丧尸入侵战役）
- **行业影响**：PS3/Xbox One版的严重缩水（无战役模式）；Specialists系统增加了英雄射击元素；丧尸模式GobbleGum微交易争议；Treyarch的暗黑科幻美学巅峰

#### Call of Duty: Infinite Warfare（使命召唤：无限战争）
- **开发商**：Infinity Ward / Raven Software / Treyarch / High Moon Studios
- **首发日期**：2016年11月4日
- **平台**：PC / PlayStation 4 / Xbox One
- **销量**：超1315万份
- **核心内容**：太空战争设定；Nick Reyes舰长和UNSA对抗SDF（定居点防卫阵线）；太空狗斗和战舰指挥。
- **关键设计**：Jackal战斗机太空作战；Combat Rigs专家装甲；Zombies in Spaceland（复古游乐园丧尸）；MW Remastered捆绑销售
- **行业影响**：预告片成为YouTube史上点踩最多的游戏预告之一（玩家不满太空设定）；但单人战役后来被认为质量极高（被部分粉丝称为"被低估的杰作"）；捆绑的《现代战争 重制版》引发争议（不单独销售）；直接导致系列回归"脚踏实地"（boots-on-the-ground）设计

### 回归本源与 battle royale 时代（2017-2021）

#### Call of Duty: WWII（使命召唤：二战）
- **开发商**：Sledgehammer Games / Raven Software
- **首发日期**：2017年11月3日
- **平台**：PC / PlayStation 4 / Xbox One
- **销量**：超1975万份
- **核心内容**：回归二战本源；大红一师（1st Infantry Division）的罗纳德·"大红"·丹尼尔斯；诺曼底到莱茵河的战役。
- **关键设计**：师团（Divisions）系统替代Create-a-Class；战争模式（War Mode，攻防推进）；总部（Headquarters）社交空间；纳粹丧尸模式（The Final Reich）
- **行业影响**：系列回归二战的战略决策（回应玩家对科幻疲劳的反馈）；总部社交空间的设计创新；战争模式受到好评；但师团系统的局限性也受到批评

#### Call of Duty: Black Ops 4（使命召唤：黑色行动4）
- **开发商**：Treyarch / Raven Software / Beenox
- **首发日期**：2018年10月12日
- **平台**：PC / PlayStation 4 / Xbox One
- **销量**：超1480万份
- **核心内容**：**无单人战役**（首次）；Blackout大逃杀模式； Specialists 系统的进化；丧尸模式（IX、Voyage of Despair、Blood of the Dead、Classified）。
- **关键设计**：Blackout（150人大逃杀，CoD地图元素）；Heist模式；Control模式；丧尸模式地图规模大幅扩展
- **行业影响**：首次取消单人战役，引发巨大争议；Blackout是CoD首次进入大逃杀领域（为2020年Warzone铺平道路）；Healer/Control/DPS的Specialists分类趋向MOBA化；Treyarch接替完成开发（原定Sledgehammer主导）

#### Call of Duty: Modern Warfare（使命召唤：现代战争 / 2019）
- **开发商**：Infinity Ward / Raven Software / High Moon Studios / Beenox
- **首发日期**：2019年10月25日
- **平台**：PC / PlayStation 4 / Xbox One
- **销量**：超3100万份
- **核心内容**：现代战争系列软重启；普莱斯队长回归（新演员Barry Sloane）；CIA特工亚历克斯（Alex）和SAS凯尔·加里克（Kyle Garrick）；法拉·卡里姆（Farah Karim）的中东故事线；"干净清白"（Clean House）等争议关卡。
- **关键设计**：**Gunsmith深度武器自定义**（5配件+Perk）；2v2 Gunfight模式；Spec Ops合作； realism 模式（无HUD）；跨平台联机（Crossplay）
- **行业影响**：软重启策略的成功典范；Gunsmith系统成为后续作品标配；跨平台联机首次引入；"Clean House"关卡的CQB战术设计广受好评；2020年3月Warzone免费大逃杀的发布将系列推向新高度

#### Call of Duty: Warzone（使命召唤：战区）
- **开发商**：Infinity Ward / Raven Software
- **首发日期**：2020年3月10日
- **平台**：PC / PlayStation 4 / Xbox One / PlayStation 5 / Xbox Series X|S
- **类型**：大逃杀（Battle Royale） / Free-to-Play
- **玩家数**：超1.1亿（2021年峰值，数据来源：Activision官方数据）
- **核心内容**：150人（后扩展至200人）大逃杀；Verdansk地图（基于现代战争地图拼接）；Gulag复活机制；Loadout空投系统；Plunder模式。
- **关键设计**：Gulag（1v1复活赛）；Buy Station购买系统；Loadout空投（使用自定义武器配置）；Gas圈（类似其他大逃毒的圈）
- **行业影响**：**免费大逃杀改变CoD商业模式**。将CoD从年度60美元销售转向Free-to-Play+战斗通行证；2020年疫情期间的全球现象；反作弊Ricochet系统的引入；2021年太平洋更新、2022年Caldera更新、2023年Warzone 2.0/Al Mazrah；累计收入超数十亿美元

#### Call of Duty: Black Ops Cold War（使命召唤：黑色行动 冷战）
- **开发商**：Treyarch / Raven Software / High Moon Studios / Sledgehammer Games / Beenox
- **首发日期**：2020年11月13日
- **平台**：PC / PlayStation 4 / PlayStation 5 / Xbox One / Xbox Series X|S
- **销量**：超2000万份
- **核心内容**：1981年冷战背景；CIA特工贝尔（Bell，玩家自定义身份）和阿德勒（Adler）追捕苏联间谍珀尔修斯（Perseus）；多结局叙事。
- **关键设计**：整合Warzone进度；Scorestreak回归；Fireteam模式；Firebase Z等丧尸模式；多结局选择
- **行业影响**：与Warzone深度整合（共享进度和商店）；跨世代发售；证明了冷战题材仍有吸引力；但开发过程中的工作室协调问题导致部分模式质量参差不齐

#### Call of Duty: Vanguard（使命召唤：先锋）
- **开发商**：Sledgehammer Games / Treyanch / Raven Software / Beenox / High Moon Studios
- **首发日期**：2021年11月5日
- **平台**：PC / PlayStation 4 / PlayStation 5 / Xbox One / Xbox Series X|S
- **销量**：超1400万份
- **核心内容**：二战特种部队的起源故事；亚瑟·金斯利、波琳娜·佩特罗娃、卢卡斯·里格斯、韦德·杰克逊四位特战兵。
- **关键设计**：Champion Hill模式（2v2/3v3竞技场）；Combat Pacing（战术/突击/闪电战）；Caldera地图（Warzone太平洋更新）
- **行业影响**：评价相对平庸，被认为是系列的又一低谷；Caldera地图替代Verdansk引发玩家社区分裂；但Champion Hill模式受到好评；2022年被《现代战争2》（2022）替代后迅速淡出

### 现代重启与新时代（2022-2026）

#### Call of Duty: Modern Warfare II（使命召唤：现代战争2 / 2022）
- **开发商**：Infinity Ward / Raven Software / Treyarch / Beenox / High Moon Studios
- **首发日期**：2022年10月28日
- **平台**：PC / PlayStation 4 / PlayStation 5 / Xbox One / Xbox Series X|S
- **销量**：超2200万份（数据来源：Activision官方数据，截至2023年）
- **核心内容**：2019《现代战争》续作；141特遣队（普莱斯、肥皂、幽灵、盖兹、亚历克斯）对抗伊朗支持的恐怖组织Al-Qatala和暗影公司（Shadow Company）的背叛。
- **关键设计**：Gunsmith 2.0（武器平台树）；DMZ模式（逃离塔科夫风格的PvPvE）；第三人称模式；Raids模式；Water Combat水下战斗
- **行业影响**：DMZ模式的实验性成功（后为《现代战争3》的Zombies模式替代）；2023年Warzone 2.0的Al Mazrah地图；发售3天收入超8亿美元；2023年TGA最佳动作游戏提名；2024年Microsoft完成687亿美元收购Activision Blizzard后首款发售的CoD

#### Call of Duty: Modern Warfare III（使命召唤：现代战争3 / 2023）
- **开发商**：Sledgehammer Games / Infinity Ward / Treyanch / Raven Software / High Moon Studios / Beenox
- **首发日期**：2023年11月10日
- **平台**：PC / PlayStation 4 / PlayStation 5 / Xbox One / Xbox Series X|S
- **销量**：超2000万份
- **核心内容**：2022《现代战争2》续作；马卡洛夫（Vladimir Makarov）回归；Open Combat Missions（开放战斗任务）；Zombies模式（DMZ风格的开放世界丧尸）。
- **关键设计**：Open Combat Missions（战役中的沙盒区域）；Zombies模式（Urzikstan开放世界，4人合作PvE）；Aftermarket Parts武器改装；Cutthroat 3v3v3模式
- **行业影响**：战役质量争议（大量开放战斗任务被认为缺乏脚本叙事密度）；但Zombies模式的DMZ化开放世界设计获得好评；Microsoft收购后首年即加入Xbox Game Pass；2024年Warzone的Urzikstan地图

#### Call of Duty: Black Ops 6（使命召唤：黑色行动6）
- **开发商**：Treyarch / Raven Software / High Moon Studios / Beenox / Activision Shanghai / Digital Legends
- **首发日期**：2024年10月25日
- **平台**：PC / PlayStation 4 / PlayStation 5 / Xbox One / Xbox Series X|S
- **销量**：发售首月表现强劲，具体数据待完整公布
- **核心内容**：1991年海湾战争背景；CIA黑色行动特工凯斯（Case）在柏林墙倒塌后的全球阴谋中调查内部叛徒；丧尸模式Liberty Falls和Terminus。
- **关键设计**：全向移动（Omnimovement）系统；经典丧尸模式回归（回合制）；战役中的沙盒任务；黑色行动6的复古UI和美学
- **行业影响**：首发即加入Xbox Game Pass（Microsoft生态战略）；全向移动系统改变多人操控感；经典丧尸模式的回归受到老玩家欢迎；海湾战争背景的历史还原；2024年TGA最佳动作游戏提名
