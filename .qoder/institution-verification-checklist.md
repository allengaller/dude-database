# 机构信息验证清单和核查标准

## 一、验证工具和渠道清单

### 官方验证渠道（第一优先级）
1. **国家企业信用信息公示系统** (http://www.gsxt.gov.cn)
   - 查询企业基本信息
   - 验证统一社会信用代码
   - 确认经营状态和经营范围

2. **各地政务服务平台**
   - 北京：北京市企业信用信息系统
   - 上海：上海市企业信用征信系统
   - 广东：广东省企业信用信息网
   - 浙江：浙江企业在线

### 商业平台验证（第二优先级）
3. **大众点评** (https://www.dianping.com)
   - 验证商户存在性
   - 核实营业地址和电话
   - 查看用户评价和营业时间

4. **美团** (https://www.meituan.com)
   - 验证商户信息
   - 核实服务项目和价格
   - 确认营业状态

5. **百度地图/高德地图**
   - 验证地址准确性
   - 确认地理位置
   - 核实周边环境

### 专业数据库（第三优先级）
6. **卫健委医疗机构查询系统**
   - 验证医院资质
   - 确认医疗机构等级
   - 核实诊疗科目

7. **行业协会会员名录**
   - 中国咖啡协会
   - 中国SPA协会
   - 各地商业联合会

## 二、机构信息核查标准

### 必须验证的信息项
- [ ] **机构全称**：与营业执照注册名称完全一致
- [ ] **统一社会信用代码**：18位有效代码
- [ ] **营业地址**：详细到门牌号，可在地图查证
- [ ] **联系电话**：官方公布的主要联系方式
- [ ] **营业时间**：官方明确公布的营业时段
- [ ] **服务范围**：与营业执照经营范围一致
- [ ] **成立时间**：准确的注册成立日期
- [ ] **法定代表人**：现任法定代表人姓名

### 禁止使用的虚构信息
- ❌ 虚构的机构名称
- ❌ 不存在的地址信息
- ❌ 无法验证的联系电话
- ❌ 夸大的服务描述
- ❌ 虚假的资质认证

## 三、不同类型机构的验证重点

### 医疗机构验证要点
```
【必须验证】
- 医疗机构执业许可证编号
- 医院等级评定证书
- 主要科室设置
- 医保定点资格
- 重点专科资质

【禁止编造】
- 虚构的医院名称
- 不存在的科室
- 虚假的医疗资质
- 夸大的医疗水平描述
```

### 餐饮娱乐机构验证要点
```
【必须验证】
- 食品经营许可证
- 公共场所卫生许可证
- 消防安全检查合格证
- 实际营业面积
- 座位数量

【禁止编造】
- 虚构的餐厅/咖啡店名称
- 不存在的特色服务
- 虚假的获奖信息
- 夸大的环境描述
```

### 服务类机构验证要点
```
【必须验证】
- 相关行业资质证书
- 从业人员职业资格
- 服务项目备案情况
- 收费标准备案
- 投诉处理机制

【禁止编造】
- 虚构的服务项目
- 不存在的技师资质
- 虚假的效果承诺
- 夸大的服务优势
```

## 四、验证流程和记录标准

### 标准验证流程
1. **初步检索**：通过官方渠道查询机构基本信息
2. **交叉验证**：通过多个渠道核实同一信息
3. **实地确认**：对重点机构进行实地走访确认
4. **定期复查**：建立定期复查机制

### 验证记录格式
```
【机构验证记录】
机构名称：[完整法定名称]
验证日期：[YYYY-MM-DD]
验证人员：[姓名]
验证渠道：[具体验证平台/网站]
验证结果：[通过/不通过]
不通过原因：[具体说明]
备注：[其他需要说明的情况]

【验证截图保存】
- 官方查询结果截图
- 地图定位截图
- 商业平台页面截图
```

## 五、质量控制标准

### 一级质量标准（优秀）
- 所有信息均可通过官方渠道验证
- 信息完整度100%
- 更新及时性良好
- 无任何虚假信息

### 二级质量标准（合格）
- 核心信息可验证（名称、地址、电话）
- 信息完整度≥90%
- 关键信息准确
- 无重大虚假信息

### 三级质量标准（不合格）
- 重要信息无法验证
- 信息完整度<80%
- 存在虚假信息
- 需要重新核实

## 六、违规处理机制

### 信息不实处理
1. **轻微不符**：限期3个工作日内补充完善
2. **严重错误**：立即下架相关内容，限期整改
3. **恶意造假**：永久删除相关内容，追究责任

### 责任追溯机制
- 建立内容责任人制度
- 完整记录修改历史
- 定期进行质量审计
- 建立奖惩机制

## 七、定期维护计划

### 月度检查
- 抽查10%的机构信息
- 验证新增机构信息
- 更新变更信息

### 季度全面核查
- 全面核查所有机构信息
- 更新失效链接
- 补充新信息

### 年度深度审查
- 委托第三方机构审查
- 用户反馈集中处理
- 制度流程优化
