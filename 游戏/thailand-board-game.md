# 泰国桌游指南

**数据说明**: 本指南基于公开可查信息整理

---

## 行业概述

泰国的桌游文化近年来快速发展，特别是在曼谷的年轻人群体和国际社区中。Sukhumvit路和Siam商圈是桌游吧最密集的区域。泰国的桌游吧通常兼具Cafe功能，以英文桌游为主，部分热门游戏有泰语版本。曼谷每年举办的BGG (Board Game Gathering)是泰国最大桌游活动。

## 推荐场所

### 桌游Cafe

**Cafe Articulture（Sukhumvit店）**
- **地址**: 39 Sukhumvit Rd, Khlong Toei Nuea, Watthana, Bangkok
- **特色**: 曼谷口碑最好的桌游Cafe之一。藏书量超200款，涵盖德式策略、派对游戏、合作游戏。提供精品咖啡和泰式简餐。有英文桌游教学。适合国际游客和本地年轻人。
- **参考价格**: 200–300 THB/人（含一杯饮品）
- **交通**: BTS Nana站或Asok站

**Board Game Cafe Play（Siam店）**
- **地址**: Siam Square Soi 5, Pathumwan, Bangkok
- **特色**: Siam商圈核心区域桌游Cafe。以派对游戏和社交推理为主，氛围轻松。适合游客和情侣约会。有泰语和英文双语服务。
- **参考价格**: 250–350 THB/人
- **交通**: BTS Siam站

**Geek & Game（Ari店）**
- **地址**: Ari Soi 4, Phaya Thai, Bangkok
- **特色**: Ari文艺区桌游吧，主打中重度策略桌游。客户群以泰国本地深度玩家和外籍人士为主。定期举办桌游比赛和教学活动。
- **参考价格**: 200–300 THB/人
- **交通**: BTS Ari站

### 清迈

**The Booksmith Board Game Cafe**
- **地址**: Nimmanhaemin Road, Chiang Mai
- **特色**: 清迈Nimman街区唯一的桌游Cafe。藏书量适中，以英文桌游为主。提供咖啡和西式简餐。适合数字游民和游客。
- **参考价格**: 200–300 THB/人
- **交通**: 宁曼路步行或Grab

**Tabletop Bangkok (Ekkamai店)**
- **地址**: Sukhumvit Soi 63 (Ekkamai), Watthana, Bangkok
- **特色**: Ekkamai文艺区的桌游吧，以欧美外籍人士社群为核心。藏书超150款英文桌游，定期举办桌游之夜。有精酿啤酒和小食。
- **参考价格**: 250–350 THB/人
- **交通**: BTS Ekkamai站

## 消费提示

- 曼谷桌游Cafe主要集中在Sukhumvit和Siam两个区域
- 多数Cafe提供英文桌游和教学，适合国际游客
- 泰国桌游文化仍在发展中，重度策略玩家可选择Geek & Game
- 清迈桌游场景较小但Nimman区的Cafe氛围好
