# 新加坡桌游指南

**数据说明**: 本指南基于公开可查信息整理

---

## 行业概述

新加坡桌游文化在2015年后快速发展，以Bugis、Orchard和Chinatown为核心区域，形成了专业桌游吧、桌游咖啡馆和社区活动三种业态。消费群体以20-35岁年轻人为主，华人社区尤其活跃，许多店铺提供中文服务。

桌游吧通常按时间收费，提供数百款桌游供自由游玩，部分店铺举办主题之夜和教学课程。与上海、深圳相比数量较少但品质稳定，整体体验偏休闲社交方向。

## 推荐场所

### 专业桌游吧

**The Board Game Cafe（Bugis）**
- **地址**: 160 Rochor Road, #02-01, Singapore 188435
- **特色**: 新加坡老牌桌游吧，收藏超过500款桌游，从经典策略到派对游戏一应俱全。提供专业导师指导新手，周末常举办主题之夜。
- **参考价格**: S$15-25/人（2小时），S$30/人（不限时）
- **交通**: 地铁武吉士站（Bugis MRT）步行5分钟

**Games@Work（Orchard）**
- **地址**: 230 Orchard Road, #03-12, Singapore 238854
- **特色**: 位于乌节路商圈，以策略类桌游见长，定期举办比赛和新品试玩会。环境宽敞，适合4-8人团体聚会。
- **参考价格**: S$20-35/人（含饮品）
- **交通**: 地铁乌节站（Orchard MRT）步行3分钟

**Boardgamecafe.net（Chinatown）**
- **地址**: 335 Smith Street, #02-05, Singapore 050335
- **特色**: 牛车水人气桌游空间，主打轻松社交氛围。收藏300余款桌游，提供中英文双语服务，适合初次体验桌游的朋友。
- **参考价格**: S$15-20/人（2小时）
- **交通**: 地铁牛车水站（Chinatown MRT）步行4分钟

### 桌游+咖啡

**The Gaming Den（Bugis）**
- **地址**: 261 Waterloo Street, #01-08, Singapore 180261
- **特色**: 桌游与精品咖啡结合的复合空间，环境文艺安静，适合2-4人小团体。
- **参考价格**: S$18-28/人（含一杯咖啡）
- **交通**: 地铁武吉士站（Bugis MRT）步行6分钟

**Meeple Cafe（Orchard）**
- **地址**: 51 Cuppage Road, #02-03, Singapore 229469
- **特色**: 桌游主题咖啡馆，招牌甜点造型灵感来自经典桌游。提供超过200款桌游，周末有亲子时段。
- **参考价格**: S$20-30/人（含甜品套餐）
- **交通**: 地铁索美塞站（Somerset MRT）步行5分钟

**Dice & Slice（Chinatown）**
- **地址**: 48 Pagoda Street, #01-02, Singapore 059207
- **特色**: 桌游搭配手工披萨的特色小店，根据人数和喜好推荐游戏，晚间氛围轻松热闹。
- **参考价格**: S$25-35/人（含餐食）
- **交通**: 地铁牛车水站（Chinatown MRT）步行3分钟

### 社区桌游活动

**Singapore Board Gamers Meetup（多地点）**
- **地址**: 各社区中心及合作场地（详见Meetup.com活动页面）
- **特色**: 新加坡最大桌游社区，每周2-3次线下活动，免费或低价参与。涵盖入门到重度策略各类游戏。
- **参考价格**: 免费-S$10/人
- **交通**: 视活动地点而定（多在Bugis或City Hall附近）

**NTUC Board Game Nights（多地点）**
- **地址**: 各NTUC Club场地及社区活动中心
- **特色**: 职总俱乐部主办的定期桌游活动，面向会员和公众开放。提供桌游教学和亲子互动环节，氛围友好。
- **参考价格**: S$5-15/人（会员优惠）
- **交通**: 视活动地点而定

## 消费提示

- 大部分桌游吧需提前预约，周末和节假日建议至少提前1天预订
- 首次到店可请店员推荐，说明人数、经验和偏好即可
- 部分店铺提供学生折扣，工作日价格通常低于周末
- 爱护桌游配件，损坏可能需赔偿；建议4-6人同行体验最佳，室内冷气较强建议携带薄外套
