# 香港桌遊指南

**數據說明**: 本指南基於公開可查資訊整理

---

## 行業概述

香港桌遊文化成熟，旺角、尖沙咀、銅鑼灣是桌遊吧最密集區域。香港桌遊圈受歐美影響深，除了華人熟悉的狼人殺、阿瓦隆，還有大量歐洲策略桌遊玩家。港人習慣在樓上舖（ Cafe）玩桌遊，邊飲咖啡邊玩，是香港獨特的桌遊社交模式。

## 推薦場所

### 桌遊Café

**Jolly Thinkers桌上遊戲咖啡廳（灣仔店）**
- **地址**: 灣仔莊士敦道
- **特色**: 香港老牌桌遊Café，藏書量全港最多（超過500款）。涵蓋德式策略、美式主題、派對遊戲。提供餐飲服務，可邊食邊玩。店員可教學。
- **參考價格**: HK$60–80/人（不限時，含一杯飲品）
- **交通**: 港鐵灣仔站

**Board Game Lounge（旺角店）**
- **地址**: 旺角彌敦道
- **特色**: 旺角區人氣桌遊吧。以派對遊戲和社交推理為主，年輕人氣氛活躍。有血染鐘樓專場。
- **參考價格**: HK$50–70/人
- **交通**: 港鐵旺角站

**Day Off Board Game Cafe（尖沙咀店）**
- **地址**: 尖沙咀加拿分道
- **特色**: 尖沙咀區桌遊Café，環境舒適。主打中重度策略桌遊和合作遊戲。適合深度玩家。
- **參考價格**: HK$55–75/人
- **交通**: 港鐵尖沙咀站

**Battle Table（銅鑼灣店）**
- **地址**: 銅鑼灣軒尼詩道
- **特色**: 銅鑼灣區桌遊+密室逃脱綜合娛樂空間。桌遊區有專人指導。
- **參考價格**: HK$65–90/人
- **交通**: 港鐵銅鑼灣站

**Mind Games Board Game Cafe（旺角第二分店）**
- **地址**: 旺角西洋菜南街
- **特色**: 旺角區另一家人氣桌遊Café。以合作遊戲和策略桌遊為主打，環境寬敞。有超過300款桌遊可供選擇。適合深度玩家。
- **參考價格**: HK$55–75/人（含一杯飲品）
- **交通**: 港鐵旺角站

## 消費提示

- 香港桌遊Café多為樓上舖，需留意大廈入口
- 多數Café提供餐飲，可當下午茶+桌遊組合
- 旺角和尖沙咀桌遊Café密度最高，步行可達多家
- 部分Café有英文桌遊教學，適合外籍玩家
