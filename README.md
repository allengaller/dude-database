# DUDE Database | 全球玩乐数据库

> **8 个城市 · 27 个类别 · 332+ 款游戏 · 240+ 篇指南**

一个覆盖全球主要城市的玩乐与生活方式数据库，包含真实场所信息（地址、价格、交通）、消费指南、行业概述。附带经典游戏数据库和单页 Web 前端。

**最新更新**: 2026年6月 — 新增 5 大玩乐类别（桌游/剧本杀/密室逃脱/KTV/谷子二次元）

## 数据管道与自动化

| 组件 | 路径 | 功能 |
|------|------|------|
| 高德API封装 | `scripts/data-pipeline/sources/amap.js` | 含缓存、限流的API调用 |
| 数据抓取 | `scripts/data-pipeline/fetch.js` | CLI入口，支持城市/类别过滤 |
| Markdown生成 | `scripts/data-pipeline/generate.js` | EJS模板渲染 |
| 大众点评爬虫 | `scripts/data-pipeline/crawlers/dianping.js` | Puppeteer爬虫（开发中） |
| 数据验证 | `scripts/tests/validate-data.js` | JSON/Markdown格式检查 |
| 单元测试 | `scripts/tests/data.test.js` | 985个Jest测试 |
| 城市配置 | `scripts/data-pipeline/config/cities.json` | 8城市，含adcode |
| 类别配置 | `scripts/data-pipeline/config/categories.json` | 27类别，含高德类型编码 |

### CI/CD (GitHub Actions)
- **数据更新**: `.github/workflows/data-update.yml` — 每周自动同步
- **数据验证**: `.github/workflows/validate-data.yml` — PR/Push时触发

### 本地使用
```bash
npm install          # 安装依赖
npm test             # 运行测试 (985 tests)
npm run validate     # 验证所有数据文件
npm run fetch:china  # 抓取国内城市数据 (需配置AMAP_KEY)
```

详见 [数据管道文档](README-DATA-PIPELINE.md)
