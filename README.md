## Database Structure

This database provides information about lifestyle and entertainment options in major cities around the world, including:

- [Hangzhou](hangzhou/)
- [Shenzhen](shenzhen/)
- [Hong Kong](hongkong/)
- [Shanghai](shanghai/)
- [New York](newyork/)
- [Thailand](thailand/)
- [Moscow](moscow/)
- [Saint Petersburg](spb/)

## File Naming Rule

The file naming format under each city directory is:

```
city-type.md
```

For example:
- shenzhen-spa.md
- hangzhou-coffee.md
